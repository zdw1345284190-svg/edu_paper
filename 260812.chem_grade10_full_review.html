三、计算题（共3题，每题9分，共27分）
20.（9分）在实验室用$\ce{MnO2}$和浓盐酸反应制取$\ce{Cl2}$：$\ce{MnO2 + 4HCl(浓) -> MnCl2 + Cl2 ^ + 2H2O}$。若用$17.4\text{g}$ $\ce{MnO2}$，计算：
（1）$\ce{MnO2}$的物质的量；（3分）
（2）生成$\ce{Cl2}$在标准状况下的体积；（3分）
（3）被氧化的$\ce{HCl}$的物质的量。（3分）

参考答案：
（1）$n(\ce{MnO2}) = 17.4/87 = 0.2\text{mol}$
（2）$n(\ce{Cl2}) = n(\ce{MnO2}) = 0.2\text{mol}$，$V = 0.2\times22.4 = 4.48\text{L}$
（3）每$4\text{mol}$ $\ce{HCl}$中$2\text{mol}$被氧化，$n(\ce{HCl})_{\text{氧化}} = 2\times0.2 = 0.4\text{mol}$
21.（9分）将$2.3\text{g}$金属钠放入足量水中，计算：
（1）生成氢气的质量；（4分）
（2）生成$\ce{NaOH}$的物质的量。（5分）

参考答案：
$\ce{2Na + 2H2O -> 2NaOH + H2 ^}$
$n(\ce{Na}) = 2.3/23 = 0.1\text{mol}$
（1）$n(\ce{H2}) = 0.1/2 = 0.05\text{mol}$，$m(\ce{H2}) = 0.05\times2 = 0.1\text{g}$
（2）$n(\ce{NaOH}) = n(\ce{Na}) = 0.1\text{mol}$
22.（9分）配制$500\text{mL}$ $0.2\text{mol/L}$的$\ce{NaCl}$溶液，需要$\ce{NaCl}$的质量是多少？简述配制步骤。

参考答案：
$n(\ce{NaCl}) = 0.5\times0.2 = 0.1\text{mol}$，$m(\ce{NaCl}) = 0.1\times58.5 = 5.85\text{g}$
步骤：计算→称量→溶解→转移→洗涤→定容→摇匀→装瓶
