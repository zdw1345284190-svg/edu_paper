高一化学（人教版必修第一册）

第二章   2.2 氯及其化合物   单元检测卷
总分：100分    考试时间：45分钟    命题范围：第二章 2.2

一、单选题（共10题，每题3分，共30分）

每题只有一个选项符合题意。

1.
下列关于氯气物理性质的叙述，正确的是（　）
答案：B — 氯气（Cl₂）在通常情况下是一种黄绿色、有刺激性气味的气体，密度（约 3.17 g/L）比空气（约 1.29 g/L）大，能溶于水。A 错在"无色"，C 错在"无味"，D 错在"密度比空气小"。
2.
实验室收集氯气应采用的方法是（　）
答案：C — 氯气密度比空气大，故应采用向上排空气法收集；氯气能溶于水（1:2），不能用排水法收集。A 错在"排水法"（Cl₂ 能溶于水），B 错在"向下排空气法"（Cl₂ 密度比空气大）。
3.
铁丝在氯气中燃烧，生成的产物是（　）
答案：B — 氯气是强氧化剂，与可变价态金属反应时生成高价氯化物。铁在氯气中燃烧：2Fe + 3Cl₂ \(\xrightarrow{\text{点燃}}\) 2FeCl₃，生成棕褐色烟（FeCl₃固体颗粒）。A 错（FeCl₂是铁与盐酸反应的产物），C 错（Cl₂只生成 FeCl₃），D 错（铁与氯气能剧烈反应）。
4.
铜丝在氯气中燃烧的实验现象是（　）
答案：A — Cu + Cl₂ \(\xrightarrow{\text{点燃}}\) CuCl₂，产生棕黄色的烟（CuCl₂固体颗粒）。B 错在"白色"，C 错在"蓝色"，D 错在"白雾"（雾是小液滴，烟是固体颗粒）。
5.
氢气在氯气中燃烧的现象是（　）
答案：A — H₂ + Cl₂ \(\xrightarrow{\text{点燃}}\) 2HCl，氢气在氯气中安静燃烧，发出苍白色火焰，生成的 HCl 气体在瓶口遇水蒸气形成盐酸小液滴，产生白雾。B 错在"黄色火焰"和"白烟"（应为白雾），C 是 H₂与 Cl₂混合光照的现象，D 明显错误。
6.
新制氯水中含有的微粒种类，下列说法正确的是（　）
答案：C — 氯气与水发生可逆反应：Cl₂ + H₂O ⇌ HCl + HClO，因此新制氯水中含有"三分子"（Cl₂、H₂O、HClO）和"三离子"（H⁺、Cl⁻、ClO⁻）。A 和 B 忽略了电离产物，D 忽略了 Cl₂ 分子和 HClO。
7.
干燥的氯气不能使有色布条褪色，但氯水能使有色布条褪色，这是因为（　）
答案：B — 干燥的 Cl₂ 不具有漂白性，Cl₂ 与水反应生成的 HClO（次氯酸）具有强氧化性，能使有色物质氧化褪色。A 错（HCl 无漂白性），C 错（Cl₂ 本身无漂白性），D 错（放热不是褪色原因）。
8.
工业上制取漂白粉的化学原理是（　）
答案：A — 工业上常用 Cl₂ 与石灰乳（Ca(OH)₂ 悬浊液）反应制取漂白粉：2Cl₂ + 2Ca(OH)₂ = Ca(ClO)₂ + CaCl₂ + 2H₂O。B 是制备 84 消毒液（NaClO）的原理，C 和 D 均不能用于制漂白粉。
9.
漂白粉在空气中放置容易失效，其主要原因是（　）
答案：B — 漂白粉在空气中失效分两步：① Ca(ClO)₂ + CO₂ + H₂O = CaCO₃ + 2HClO；② 2HClO \(\xrightarrow{\text{光}}\) 2HCl + O₂↑。A 错在"Ca(ClO)₂ 见光分解"（实际是 HClO 见光分解），C 和 D 也非主要原因。
10.
下列有关氯水的说法，错误的是（　）
答案：D — 新制氯水呈浅黄绿色是因为存在 Cl₂ 分子（A 正确）；氯水中含 H⁺（酸性）、Cl₂/HClO（氧化性）、HClO（漂白性，B 正确）；久置氯水中，HClO 分解促进 Cl₂ 与 H₂O 持续反应，最终成为稀盐酸（C 正确）。氯水久置过程中 Cl₂ 不断被消耗，c(Cl₂) 逐渐减小（D 错误）。

二、多选题（共3题，每题4分，共12分）

每题有多个选项符合题意。全对得4分，部分选对得2分，有错选得0分。

11.
关于新制氯水的成分和性质，下列说法正确的有（　）
答案：A, B, C — A 对：新制氯水中存在 Cl₂ + H₂O ⇌ HCl + HClO 平衡，含有三种分子。B 对：HCl 完全电离出 H⁺ 和 Cl⁻，HClO 部分电离出 H⁺ 和 ClO⁻，故三种主要离子均存在。C 对：HClO 具有强氧化性，能使有色布条褪色。D 错：加入 NaHCO₃ 产生气泡是与 H⁺ 反应所致（HCO₃⁻ + H⁺ = CO₂↑ + H₂O），并非因为存在 HCl 分子（HCl 是强电解质，完全电离）。
12.
下列关于氯气化学性质的说法，正确的有（　）
答案：B, C, D — A 错：Cl₂ 是强氧化剂，与 Fe 反应生成 FeCl₃ 而非 FeCl₂。B 对：Cu + Cl₂ \(\xrightarrow{\text{点燃}}\) CuCl₂，产生的 CuCl₂ 固体颗粒形成棕黄色的烟。C 对：H₂ + Cl₂ \(\xrightarrow{\text{点燃}}\) 2HCl，发出苍白色火焰。D 对：Cl₂ + H₂O ⇌ HCl + HClO，这是氯水能同时具有酸性和漂白性的根本原因。
13.
下列关于漂白粉的说法，正确的有（　）
答案：B, C, D — A 错：漂白粉的主要成分是 CaCl₂ 和 Ca(ClO)₂，但有效成分仅为 Ca(ClO)₂。B 对：漂白粉的漂白原理是 Ca(ClO)₂ + CO₂ + H₂O = CaCO₃ + 2HClO，HClO 具有强氧化性起漂白作用。C 对：该反应消耗 Ca(ClO)₂，且生成的 HClO 易分解。D 对：密封防止 CO₂ 进入，避光防止 HClO 分解，干燥防止潮解。

三、填空题（共6题，每题3分，共18分）

14. 氯气在通常情况下是一种
色、有 气味的气体。
答案：黄绿（或黄绿色）；刺激性 — 氯气（Cl₂）的物理性质：黄绿色气体、有刺激性气味、密度比空气大、能溶于水（1 体积水约溶解 2 体积 Cl₂）。
15. 新制氯水中含有的分子有 Cl\(_2\)、H\(_2\)O 和
（填化学式）；含有的阳离子为 （填离子符号）。
答案：HClO；H⁺（或 H⁺） — 新制氯水中含有的分子（三分子）：Cl₂、H₂O、HClO；含有的离子（三离子）：H⁺、Cl⁻、ClO⁻。其中阳离子即为 H⁺（氢离子）。
16. 氯气与水反应的化学方程式为 Cl\(_2\) + H\(_2\)O =
+ （填化学式）。
答案：HCl；HClO — Cl₂ + H₂O ⇌ HCl + HClO，该反应为可逆反应，生成的 HCl 是强酸（完全电离），HClO 是弱酸（具有漂白性）。
17. 氯气与 NaOH 溶液反应的化学方程式为 Cl\(_2\) + 2NaOH =
+ + H\(_2\)O（填化学式）。
答案：NaCl；NaClO — Cl₂ + 2NaOH = NaCl + NaClO + H₂O，该反应生成的 NaClO（次氯酸钠）是 84 消毒液的有效成分，与漂白粉的 Ca(ClO)₂ 漂白原理类似。
18. 漂白粉的有效成分是
（填化学式）；工业上制备漂白粉所用的原料是 Cl\(_2\) 和 （填化学式）。
答案：Ca(ClO)₂（或 Ca(ClO)₂）；Ca(OH)₂（或 Ca(OH)₂） — 工业上制备漂白粉：2Cl₂ + 2Ca(OH)₂（石灰乳）= Ca(ClO)₂ + CaCl₂ + 2H₂O。有效成分是 Ca(ClO)₂（次氯酸钙）。注意石灰乳是 Ca(OH)₂ 悬浊液，不是澄清石灰水。
19. 实验室检验 Cl\(^-\) 的方法是：向待测液中滴加
溶液（填化学式）和稀 HNO\(_3\)，若产生 色沉淀，则证明含有 Cl\(^-\)。
答案：AgNO₃（或 AgNO₃）；白 — Cl⁻ 的检验方法：向待测液中滴加 AgNO₃ 溶液，若产生白色沉淀（AgCl），再滴加稀 HNO₃，沉淀不溶解，则证明含有 Cl⁻。离子方程式：Ag⁺ + Cl⁻ = AgCl↓（白色）。加入稀 HNO₃ 的目的是排除 CO₃²⁻ 等干扰（Ag₂CO₃ 沉淀可溶于稀 HNO₃）。

20. （10分）氯气与金属及非金属的反应
(1)（3分）写出铁在氯气中燃烧的化学方程式，并描述实验现象。
(2)（3分）写出氢气在氯气中燃烧的化学方程式，并描述实验现象。
(3)（4分）将 0.3 mol Cl\(_2\) 通入足量铁粉中充分反应，理论上生成 FeCl\(_3\) 的物质的量为 mol；参与反应的 Fe 的物质的量为 mol。
参考答案：
(1) 2Fe + 3Cl₂ \(\xrightarrow{\text{点燃}}\) 2FeCl₃（2分）
现象：铁丝在氯气中剧烈燃烧，产生棕褐色的烟（FeCl₃固体颗粒）。（1分）
(2) H₂ + Cl₂ \(\xrightarrow{\text{点燃}}\) 2HCl（2分）
现象：氢气在氯气中安静地燃烧，发出苍白色火焰，瓶口有白雾（HCl 气体遇水蒸气形成的盐酸小液滴）。（1分）
(3) 0.2 mol（2分）；0.2 mol（2分）
计算：2Fe + 3Cl₂ → 2FeCl₃，n(FeCl₃) = 2/3 × n(Cl₂) = 2/3 × 0.3 = 0.2 mol，n(Fe) = n(FeCl₃) = 0.2 mol
21. （10分）氯水的成分与性质探究
(1)（3分）写出 Cl\(_2\) 与 H\(_2\)O 反应的化学方程式。
(2)（3分）向新制氯水中滴加紫色石蕊试液，先变红后褪色，请解释原因。
(3)（4分）新制氯水在阳光下久置后，最终溶液中的溶质是 （填化学式）；写出久置过程中发生分解反应的化学方程式：
参考答案：
(1) Cl₂ + H₂O ⇌ HCl + HClO（3分）
(2) 原因：氯水中含 H⁺，使石蕊试液变红（酸性）；（1.5分）
氯水中含 HClO，具有强氧化性，将有色物质氧化褪色（漂白性）。（1.5分）
(3) HCl（2分，盐酸或稀盐酸均可）
HClO 分解的化学方程式：2HClO \(\xrightarrow{\text{光照}}\) 2HCl + O₂↑（2分）
解释：久置过程中，Cl₂ 与 H₂O 持续反应，HClO 不断分解（2HClO → 2HCl + O₂），促使平衡 Cl₂ + H₂O ⇌ HCl + HClO 正向移动，最终 Cl₂ 完全转化为 HCl，溶液变为稀盐酸。
22. （10分）漂白粉的制备、漂白原理与失效
(1)（3分）写出工业上利用 Cl\(_2\) 与石灰乳反应制备漂白粉的化学方程式。
(2)（3分）写出漂白粉在空气中起漂白作用的化学方程式（Ca(ClO)\(_2\) 与 CO\(_2\) 和 H\(_2\)O 反应）。
(3)（4分）漂白粉在空气中长期放置会完全失效。写出失效过程中 HClO 分解的化学方程式，并说明为什么漂白粉需要密封、避光保存。
参考答案：
(1) 2Cl₂ + 2Ca(OH)₂（石灰乳）= Ca(ClO)₂ + CaCl₂ + 2H₂O（3分）
(2) Ca(ClO)₂ + CO₂ + H₂O = CaCO₃↓ + 2HClO（3分）
(3) HClO 分解：2HClO \(\xrightarrow{\text{光照}}\) 2HCl + O₂↑（2分）
说明（2分）：
① 在空气中，Ca(ClO)₂ 与 CO₂、H₂O 反应生成 HClO，HClO 见光分解，使漂白粉失去漂白效果。
② 同时，分解产生的 HCl 会与未分解的 CaCO₃ 反应：CaCO₃ + 2HCl = CaCl₂ + CO₂↑ + H₂O，使漂白粉结块变质。
③ 因此漂白粉需密封保存（防止 CO₂ 进入）、避光保存（防止 HClO 分解）、干燥保存（防止潮解）。
23. （10分）Cl\(^-\) 检验与氯气性质综合推断
(1)（2分）简述实验室检验 Cl\(^-\) 的实验操作方法及现象。
(2)（4分）某无色透明溶液可能含有 Cl\(^-\)、CO\(_3^{2-}\) 中的一种或两种。进行如下实验：

  ② 继续向试管中滴加 AgNO\(_3\) 溶液，产生白色沉淀 → 证明含有 （填离子符号）
  ③ 写出产生白色沉淀的离子方程式：
(3)（4分）将 Cl\(_2\) 通入滴有紫色石蕊试液的蒸馏水中，描述可能观察到的现象，并写出 Cl\(_2\) 与 H\(_2\)O 反应的化学方程式，结合方程式解释产生该现象的原因。
参考答案：
(1)（2分）取少量待测液于试管中，滴加几滴 AgNO₃ 溶液，若产生白色沉淀，再滴加稀 HNO₃，沉淀不溶解，则证明原溶液中含有 Cl⁻。
离子方程式：Ag⁺ + Cl⁻ = AgCl↓（白色）
(2)（4分）① CO₃²⁻（1分）；② Cl⁻（1分）
③ Ag⁺ + Cl⁻ = AgCl↓（2分）
分析：滴加稀 HNO₃ 产生无色气泡（CO₂），证明有 CO₃²⁻；HNO₃ 过量可排除 CO₃²⁻ 干扰（Ag₂CO₃ 溶于稀 HNO₃），继续滴加 AgNO₃ 产生白色沉淀（AgCl），证明有 Cl⁻。
(3)（4分）现象：紫色石蕊试液先变红后褪色。（1分）
化学方程式：Cl₂ + H₂O ⇌ HCl + HClO（1分）
解释：Cl₂ 与水反应生成 HCl 和 HClO。HCl 完全电离出 H⁺，使石蕊变红（酸性）；HClO 具有强氧化性，将红色物质氧化褪色（漂白性）。（2分）
