一、单选题（共10题，每题4分，共40分）
1. 与$-30^\circ$终边相同的角是（  ）
答案：B（$360^\circ+(-30^\circ)=330^\circ$）
2. 下列各角中，属于第三象限角的是（  ）
答案：C（$180^\circ\sim270^\circ$）
3. 已知角$\theta$终边上一点$P(3,-4)$，则$\sin\theta$等于（  ）
答案：A（$r=5$，$\sin\theta = y/r = -4/5$）
4. $\cos(-60^\circ)$等于（  ）
答案：C（$\cos(-60^\circ)=\cos60^\circ=\frac12$）
5. 已知$\sin\alpha=\frac{3}{5}$，且$\alpha$在第二象限，则$\cos\alpha$等于（  ）
答案：B（$\cos^2\alpha=1-\sin^2\alpha=\frac{16}{25}$，第二象限$\cos$为负）
6. $\tan 150^\circ$等于（  ）
答案：C（$\tan150^\circ = \tan(180^\circ-30^\circ) = -\tan30^\circ = -\frac{\sqrt{3}}{3}$）
7. 下列三角函数值中，为负值的是（  ）
答案：D（$100^\circ$二象限$\sin>0$；$200^\circ$三象限$\cos<0$... 等等$\cos(-30^\circ)=\cos30^\circ>0$，应该是$\cos200^\circ<0$为负）
8. 若$\sin\theta\cdot\cos\theta<0$，则$\theta$所在的象限是（  ）
答案：A（异号，$\sin>0,\cos<0$二象限；$\sin<0,\cos>0$四象限）
9. 弧长公式$l=|\alpha|r$中，$\alpha$的单位是（  ）
答案：B
10. 半径为2，圆心角为$60^\circ$的扇形的弧长为（  ）
答案：C（$60^\circ=\pi/3$，$l = 2\times\pi/3 = 2\pi/3$）
二、填空题（共5题，每题4分，共20分）
11. 将$300^\circ$化成弧度：______。

答案：$\frac{5\pi}{3}$
12. 将$\frac{5\pi}{6}$化成角度：______。

答案：$150^\circ$
13. $\sin^2 30^\circ + \cos^2 30^\circ =$______。

答案：1
14. 已知$\tan\alpha = 2$，则$\frac{\sin\alpha}{\cos\alpha}=$______。

答案：2
15. 若$\sin\alpha = \frac{1}{2}$，且$\alpha$是第一象限角，则$\cos\alpha =$______。

答案：$\frac{\sqrt{3}}{2}$
三、解答题（共3题，共40分）
16.（12分）已知角$\alpha$终边上一点$P(-3,4)$。
（1）求$r=OP$的长度；（4分）
（2）求$\sin\alpha$、$\cos\alpha$、$\tan\alpha$的值。（8分）

参考答案：
（1）$r = \sqrt{(-3)^2+4^2} = \sqrt{25} = 5$
（2）$\sin\alpha = y/r = 4/5$，$\cos\alpha = x/r = -3/5$，$\tan\alpha = y/x = -4/3$
17.（14分）化简：
（1）$\sin(-30^\circ) + \cos 120^\circ + \tan 225^\circ$；（6分）
（2）$\frac{\sin(180^\circ-\alpha)\cos(360^\circ-\alpha)}{\tan(180^\circ+\alpha)}$。（8分）

参考答案：
（1）$\sin(-30^\circ)=-\frac12$，$\cos120^\circ=-\frac12$，$\tan225^\circ=1$，原式$=-\frac12-\frac12+1=0$
（2）$\sin(180^\circ-\alpha)=\sin\alpha$，$\cos(360^\circ-\alpha)=\cos\alpha$，$\tan(180^\circ+\alpha)=\tan\alpha$，原式$=\frac{\sin\alpha\cos\alpha}{\tan\alpha} = \frac{\sin\alpha\cos\alpha}{\sin\alpha/\cos\alpha} = \cos^2\alpha$
18.（14分）已知$\sin\alpha + \cos\alpha = \frac{1}{5}$，且$0<\alpha<\pi$。
（1）求$\sin\alpha\cos\alpha$的值；（6分）
（2）求$\sin\alpha - \cos\alpha$的值。（8分）

参考答案：
（1）$(\sin\alpha+\cos\alpha)^2 = 1+2\sin\alpha\cos\alpha = \frac{1}{25}$，$\therefore \sin\alpha\cos\alpha = \frac{1}{25}\times\frac12 - \frac12 = -\frac{12}{25}$
（2）$(\sin\alpha-\cos\alpha)^2 = 1-2\sin\alpha\cos\alpha = 1+\frac{24}{25} = \frac{49}{25}$
$\because 0<\alpha<\pi$，且$\sin\alpha+\cos\alpha=\frac15>0$，$\sin\alpha\cos\alpha<0$，$\therefore \alpha$在第二象限且$|\sin\alpha|>|\cos\alpha|$，$\therefore \sin\alpha-\cos\alpha = \frac75$
