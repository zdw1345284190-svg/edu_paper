# 生物 · 必修1 分子与细胞（人教版）

---

## 第一章 — 走进细胞

### 1.1 细胞是生命活动的基本单位
- **细胞学说**（施莱登、施旺）：
  - 细胞是一个有机体，一切动植物都由细胞发育而来
  - 细胞是一个相对独立的单位
  - 新细胞由老细胞分裂产生
  - **意义**：揭示了动物和植物的统一性，标志生物学研究进入细胞水平
- **生命系统的结构层次**：
  ```
  细胞 → 组织 → 器官 → 系统 → 个体 → 种群 → 群落 → 生态系统 → 生物圈
  ```

### 1.2 细胞的多样性和统一性
- **原核细胞 vs 真核细胞**：

  | 特征 | 原核细胞 | 真核细胞 |
  |------|---------|---------|
  | 细胞核 | 无核膜包被（拟核） | 有核膜包被的细胞核 |
  | 染色体 | 环状 DNA，无染色体 | DNA + 蛋白质 → 染色体 |
  | 细胞器 | 只有核糖体 | 多种细胞器 |
  | 代表生物 | 细菌、蓝藻（蓝细菌） | 动物、植物、真菌 |

- **蓝细菌**：能进行光合作用（含叶绿素和藻蓝素），无叶绿体
- **显微镜使用**：
  - 放大倍数 = 目镜 × 物镜
  - 视野亮度、细胞数目与放大倍数的关系
  - 高倍镜使用步骤：低倍镜找到目标 → 移至中央 → 换高倍镜 → 调细准焦螺旋

## 第二章 — 组成细胞的分子

### 2.1 细胞中的元素和化合物
- **元素组成**：
  - 大量元素：C、H、O、N、P、S、K、Ca、Mg 等
  - 微量元素：Fe、Mn、B、Zn、Mo、Cu（铁锰硼锌钼铜）
  - **最基本元素**：C（生物大分子以碳链为骨架）
- **化合物含量**：
  - 水 > 蛋白质 > 脂质 > 糖类 > 无机盐
  - 占细胞干重最多的化合物：蛋白质
- **检测方法**：
  - 还原糖 + 斐林试剂 → 砖红色沉淀（水浴加热）
  - 脂肪 + 苏丹Ⅲ → 橘黄色 / 苏丹Ⅳ → 红色
  - 蛋白质 + 双缩脲试剂 → 紫色
  - 淀粉 + 碘液 → 蓝色

### 2.2 细胞中的无机物
- **水**：
  - 自由水（溶剂、运输、参与代谢）vs 结合水（构成细胞结构）
  - 自由水/结合水比值影响代谢强度与抗逆性
- **无机盐**：
  - 存在形式：离子（主要）
  - 功能：构成化合物（Fe→血红蛋白、Mg→叶绿素）、维持渗透压、维持酸碱平衡

### 2.3 细胞中的糖类和脂质
- **糖类（主要能源物质）**：
  | 类别 | 种类 | 作用 |
  |------|------|------|
  | 单糖 | 葡萄糖、果糖、半乳糖、核糖、脱氧核糖 | 不能水解 |
  | 二糖 | 蔗糖、麦芽糖、乳糖 | 两分子单糖 |
  | 多糖 | 淀粉、纤维素、糖原（肝糖原/肌糖原）、几丁质 | 储能/结构 |

- **脂质**：
  - **脂肪**：储能、保温、缓冲、减压
  - **磷脂**：细胞膜的基本骨架（磷脂双分子层）
  - **固醇**：胆固醇（构成膜/参与代谢）、性激素（调节）、维生素 D（促进钙吸收）

### 2.4 蛋白质
- **基本单位**：氨基酸（20 种，8 种必需氨基酸人体不能合成）
- **氨基酸结构通式**：一个中心 C 原子连—NH₂、—COOH、—H、—R
- **脱水缩合**：
  - 肽键数 = 脱去水分子数 = 氨基酸数 − 肽链数
  - 蛋白质相对分子质量 = n × 氨基酸平均分子量 − 18 × (n − m)
  - 至少游离的氨基/羧基数 = 肽链数
- **蛋白质结构层次**：氨基酸 → 肽链 → 盘曲折叠 → 蛋白质
- **蛋白质多样性原因**：氨基酸的种类、数目、排列顺序、空间结构不同
- **功能**：结构（胶原蛋白）、催化（酶）、运输（血红蛋白）、调节（胰岛素）、免疫（抗体）

### 2.5 核酸
- **基本单位**：核苷酸（一分子含氮碱基 + 一分子五碳糖 + 一分子磷酸）
- **脱氧核糖核酸 DNA**：T = A, C ≡ G（双螺旋），主要分布在细胞核
- **核糖核酸 RNA**：U 代替 T，单链，主要分布在细胞质
- **功能**：携带遗传信息，控制蛋白质合成

## 第三章 — 细胞的基本结构

### 3.1 细胞膜
- **成分**：磷脂（约 50%）+ 蛋白质（约 40%）+ 少量糖类
- **结构**：流动镶嵌模型（辛格和尼科尔森）
  - 磷脂双分子层 → 基本骨架
  - 蛋白质镶嵌/贯穿其中
  - 糖蛋白 → 识别作用（糖被）
- **特点**：**流动性**（结构特点）、**选择透过性**（功能特点）
- **功能**：边界、控制物质进出、信息传递（受体）

### 3.2 细胞器
- **双层膜**：
  - **线粒体**：有氧呼吸主要场所（"动力车间"），含少量 DNA
  - **叶绿体**：光合作用场所（"养料制造厂"），含少量 DNA（植物特有）
- **单层膜**：
  - **内质网**：蛋白质合成加工（粗面）、脂质合成（滑面）
  - **高尔基体**：加工、包装、运输（植物中与细胞壁形成有关）
  - **液泡**：储存物质、维持渗透压（植物特有）
  - **溶酶体**：消化异物与衰老细胞器
- **无膜**：
  - **核糖体**：蛋白质合成场所（游离核糖体/附着核糖体）
  - **中心体**：与有丝分裂有关（动物/低等植物特有）
- **细胞骨架**：蛋白质纤维网络，维持形态、支持运动

### 3.3 细胞核
- **结构**：
  - 核膜（双层膜，上有核孔）
  - 核仁（与 rRNA 合成有关）
  - 染色质（DNA + 组蛋白，易被碱性染料染色）
- **功能**：遗传信息库，细胞代谢和遗传的控制中心
- **染色质与染色体的关系**：同一物质在不同时期的不同形态

## 第四章 — 细胞的物质输入和输出

### 4.1 被动运输
- **扩散与渗透**：高浓度 → 低浓度，不消耗能量
- **自由扩散**：顺浓度梯度，不需载体（如 O₂、CO₂、H₂O、甘油、乙醇）
- **协助扩散**：顺浓度梯度，需载体蛋白/通道蛋白（如葡萄糖进入红细胞、离子通道）
- **渗透作用**：水分子从低浓度溶液 → 高浓度溶液的扩散
- **质壁分离与复原**（植物细胞）：外界溶液浓度 > 细胞液浓度 → 失水（分离）

### 4.2 主动运输
- 方向：低浓度 → 高浓度（逆浓度梯度）
- 条件：需载体蛋白 + 消耗能量（ATP）
- 举例：Na⁺/K⁺ 泵、小肠上皮吸收葡萄糖/氨基酸
- 意义：保证细胞按需吸收物质

### 4.3 胞吞与胞吐
- 大分子物质（蛋白质、多糖、颗粒）的运输方式
- 依赖细胞膜的流动性，消耗能量
- 举例：吞噬细胞吞噬细菌、神经递质的分泌

## 第五章 — 细胞的能量供应和利用

### 5.1 降低化学反应活化能的酶
- **酶的本质**：大多数为蛋白质，少数为 RNA
- **作用机理**：降低化学反应活化能（对比无机催化剂，降低更显著）
- **特性**：**高效性**、**专一性**、作用条件温和
- **影响酶活性的因素**：温度（最适温度→失活）、pH（最适 pH→失活）
- 酶活性 ≠ 酶促反应速率（反应速率还受底物浓度、酶浓度影响）

### 5.2 细胞的能量"货币"——ATP
- **结构**：A—P~P~P（A = 腺苷，P = 磷酸基团，~ = 高能磷酸键）
- **ATP 与 ADP 的相互转化**：
  - ATP →(水解)→ ADP + Pi + 能量（放能）
  - ADP + Pi + 能量 →(合成)→ ATP（吸能）
- 特点：含量少，转化快，动态平衡

### 5.3 细胞呼吸
- **有氧呼吸（主要方式）**：
  ```
  场所：细胞质基质 → 线粒体基质 → 线粒体内膜
  C₆H₁₂O₆ + 6O₂ →(酶)→ 6CO₂ + 6H₂O + 能量（大量 ATP）
  ```
  - 第一阶段（糖酵解）：细胞质基质，葡萄糖→丙酮酸+[H]+少量 ATP
  - 第二阶段（柠檬酸循环）：线粒体基质，丙酮酸→CO₂+[H]+少量 ATP
  - 第三阶段（氧化磷酸化）：线粒体内膜，[H]+O₂→H₂O+大量 ATP
- **无氧呼吸**：
  - 场所：细胞质基质
  - 产物：乳酸（动物/马铃薯块茎）或酒精+CO₂（植物/酵母菌）
  - C₆H₁₂O₆ →(酶)→ 2C₃H₆O₃ + 少量能量（乳酸发酵）
  - C₆H₁₂O₆ →(酶)→ 2C₂H₅OH + 2CO₂ + 少量能量（酒精发酵）
- 有氧呼吸与无氧呼吸的比较（从场所、产物、能量三个角度）

### 5.4 光合作用
- **叶绿体结构**：类囊体（堆叠成基粒，含光合色素）+ 基质
- **光合色素**：叶绿素 a（蓝绿色）、叶绿素 b（黄绿色）、类胡萝卜素（胡萝卜素和叶黄素）
- **光合作用过程**：
  ```
  总反应：6CO₂ + 6H₂O →(光能,叶绿体)→ C₆H₁₂O₆ + 6O₂
  ```
  - **光反应**（类囊体薄膜）：光能 → ATP+[H]（NADPH），光解水放 O₂
  - **暗反应**（叶绿体基质）：CO₂ 固定 → C₃ 还原 → (CH₂O)（消耗 ATP 和 [H]）
- **影响因素**：光照强度、CO₂ 浓度、温度、（注意光饱和点和补偿点）
- 化能合成作用：利用无机物氧化释放的化学能合成有机物（如硝化细菌）

## 第六章 — 细胞的生命历程

### 6.1 细胞的增殖
- **细胞周期**：连续分裂的细胞从一次分裂完成到下一次分裂完成
  - 分裂间期（G₁→S 期 DNA 复制→G₂）：时间长，占 90-95%
  - 分裂期（M 期）：前期 → 中期 → 后期 → 末期
- **有丝分裂**（以植物为例）：
  - **前期**：染色质→染色体，核膜消失，纺锤体形成
  - **中期**：染色体排列在赤道板（染色体形态稳定、数目清晰——**观察最佳时期**）
  - **后期**：着丝粒分裂，姐妹染色单体分开向两极移动（染色体数加倍）
  - **末期**：染色体→染色质，核膜重现，细胞板形成→细胞壁
- 动物与植物有丝分裂区别：
  - 前期：动物由中心体发出星射线形成纺锤体
  - 末期：动物细胞膜向内凹陷缢裂成两个细胞
- **有丝分裂的意义**：将亲代染色体精确复制后平均分配到两个子细胞中

### 6.2 细胞分化
- 概念：后代细胞在形态、结构和功能上发生稳定性差异的过程
- 特点：持久性、稳定性、不可逆性
- **实质**：基因的选择性表达（细胞中遗传物质不变）
- 全能性：已分化细胞仍具有发育成完整个体的潜能（受精卵 > 生殖细胞 > 体细胞）

### 6.3 细胞的衰老和死亡
- **细胞衰老特征**：
  - 水分减少（萎缩）
  - 酶活性降低（代谢减慢）
  - 色素积累（老年斑）
  - 细胞膜通透性改变（物质运输功能下降）
- **细胞死亡**：
  - 细胞凋亡（**程序性死亡**，主动过程，对机体有利）
  - 细胞坏死（意外损伤，被动过程，对机体有害）

## 常见计算题型

| 类型 | 公式/方法 |
|------|----------|
| 蛋白质相对分子质量 | n × aa 平均分子量 − 18 × (n − m) |
| 肽键数 | n − m（n=氨基酸数，m=肽链数） |
| DNA 碱基比例 | A=T, G=C ⇒ A+G=T+C=50% |
| 有丝分裂染色体数 | 后期加倍（着丝粒分裂），末期减半 |
| 光合/呼吸速率 | 净光合 = 总光合 − 呼吸消耗 |
