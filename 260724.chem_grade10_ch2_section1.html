一、单选题
1. C — 钠是银白色金属，质地柔软（可用刀切割），密度比水小（约0.97 g/cm³）。A错在"硬度大、密度比水大"，B错在"暗灰色"，D错在"硬度大、导电性差"。
2. A — 取用钠时用镊子夹取，用滤纸吸干表面的煤油，在玻璃片上用小刀切割。B错在"直接用手"，C错在"直接暴露在空气中"，D错在"药匙"和"在水中切割"。
3. B — 钠在常温下与氧气反应生成白色的Na₂O（氧化钠）：4Na + O₂ = 2Na₂O。加热（燃烧）时才生成Na₂O₂（过氧化钠）。
4. B — 钠在空气中加热时先熔化成小球（钠的熔点低），然后剧烈燃烧，火焰呈黄色（钠的特征焰色），生成淡黄色的Na₂O₂。A是常温氧化的现象，C错在"紫色"和"白色"，D错在"白色固体"。
5. B — 反应放热使钠熔化，同时钠的熔点低（约97.8℃），所以熔化成闪亮的小球。A描述的是密度导致浮在水面，C和D与熔化原因无关。
6. D — Na₂O是碱性氧化物，与酸反应只生成盐和水，不产生O₂（产生O₂是Na₂O₂的性质）。A、B、C均正确。
7. B — Na₂O₂与人呼出的H₂O和CO₂反应生成O₂：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑，2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂，因此可用作呼吸面具的供氧剂。
8. C — Na₂CO₃俗称纯碱（苏打），水溶液因CO₃²⁻水解而显碱性。A错（小苏打是NaHCO₃），B错（Na₂CO₃受热不分解），D错（与酸反应产生CO₂）。
9. B — NaHCO₃是可溶性盐，写离子方程式时应拆成离子：HCO₃⁻ + H⁺ = CO₂↑ + H₂O。A是CO₃²⁻与酸的反应（适用于Na₂CO₃），C未拆NaHCO₃，D不是与酸反应。
10. D — A：4Na + O₂ = 2Na₂O（可一步），B：Na₂O + H₂O = 2NaOH（可一步），C：Na₂CO₃ + CO₂ + H₂O = 2NaHCO₃（可一步），D：NaHCO₃不能一步转化为Na₂O（需多步反应）。
二、多选题
11. B, C, D — A错：钠的密度比水小（约0.97 g/cm³），因此浮在水面。B对：反应放热使钠熔化成小球。C对：产生的H₂推动钠球游动。D对：生成的NaOH使酚酞变红。
12. B, C, D — A错：Na₂CO₃俗称苏打（纯碱），NaHCO₃俗称小苏打，正好说反。B对：CO₃²⁻水解程度大于HCO₃⁻，故碱性更强。C对：2NaHCO₃ \(\xrightarrow{\triangle}\) Na₂CO₃ + CO₂↑ + H₂O。D对：HCO₃⁻可直接与H⁺反应，速率更快。
13. A, B, C — A对：Na₂O₂是淡黄色固体（而Na₂O是白色）。B对：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑。C对：与H₂O和CO₂反应生成O₂。D错：Na₂O₂属于过氧化物，不是碱性氧化物（与酸反应还生成O₂）。
三、填空题
14. 熔 — 钠与水反应放热，钠的熔点低（约97.8℃），因此熔化成闪亮的小球。
15. 黄；淡黄 — 钠燃烧时火焰呈黄色（钠元素的特征焰色反应），生成的Na₂O₂是淡黄色固体。
16. O₂；1 — 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑。Na₂O₂中O为-1价，发生歧化反应：部分O升到0价（O₂），部分降到-2价（OH⁻），每mol Na₂O₂转移1 mol电子。
17. CO₂；Na₂CO₃ — 2NaHCO₃ \(\xrightarrow{\triangle}\) Na₂CO₃ + CO₂↑ + H₂O。产生的CO₂能使澄清石灰水变浑浊，这是鉴别NaHCO₃的重要方法。
18. 0.97；Na₂O — 钠的密度为0.97 g/cm³，比水小；常温下与O₂反应生成白色的Na₂O（氧化钠）。
19. CaCl₂（或BaCl₂）；Na₂CO₃ — CaCl₂ + Na₂CO₃ = CaCO₃↓ + 2NaCl，产生白色沉淀。CaCl₂与NaHCO₃不反应（无沉淀、无气体），故可鉴别。
四、解答题（参考解答）
20. （10分）
(1) 2Na + 2H₂O = 2NaOH + H₂↑（3分）
(2) ①浮：钠的密度（0.97 g/cm³）小于水，浮在水面；（1分）
  ②熔：反应放热，且钠的熔点低（约97.8℃），钠熔化成闪亮的小球；（1分）
  ③游：产生的H₂气体推动钠球在水面上四处游动；（1分）
  ④响：H₂与空气摩擦发出嘶嘶响声；（0.5分）
  ⑤红：生成的NaOH使滴有酚酞的溶液变红。（0.5分）
(3) 0.05 mol（1.5分）；0.1 mol（1.5分）
  由2Na ~ H₂ ~ 2NaOH，n(H₂) = ½ × 0.1 = 0.05 mol，n(NaOH) = 0.1 mol
21. （10分）
(1) 2Na₂O₂ + 2H₂O = 4NaOH + O₂↑（3分）
(2) 2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂（3分）
(3) 1.6 g（4分，其中计算过程3分，结果1分）
  M(Na₂O₂) = 78 g/mol，n(Na₂O₂) = 7.8 g ÷ 78 g/mol = 0.1 mol
  2Na₂O₂ ~ O₂，n(O₂) = ½ n(Na₂O₂) = 0.05 mol，m(O₂) = 0.05 mol × 32 g/mol = 1.6 g
22. （10分）
(1) 2NaHCO₃ \(\xrightarrow{\triangle}\) Na₂CO₃ + CO₂↑ + H₂O（3分）
(2) NaHCO₃（1.5分）；HCO₃⁻ + H⁺ = CO₂↑ + H₂O（1.5分）
(3) 加热（或充分加热至恒重，2分）。利用NaHCO₃受热分解转化为Na₂CO₃，而Na₂CO₃受热不分解的原理除杂。
(4) CO₂（2分）。Na₂CO₃ + CO₂ + H₂O = 2NaHCO₃，通入足量CO₂可将Na₂CO₃转化为NaHCO₃。
23. （10分）
(1) A：Na、B：Na₂O、C：NaOH、D：Na₂CO₃、E：NaHCO₃（各1分，共5分）
  分析：A为Na单质；B为白色固体碱性氧化物→Na₂O；C为碱→NaOH；D俗称纯碱→Na₂CO₃；E俗称小苏打→NaHCO₃。
(2) 4Na + O₂ = 2Na₂O（2分）
(3) Na₂CO₃ + CO₂ + H₂O = 2NaHCO₃（2分）
(4) 2NaHCO₃ \(\xrightarrow{\triangle}\) Na₂CO₃ + CO₂↑ + H₂O（2分）
