三、计算题（共2题，每题16分，共32分）
18.（16分）在实验室中用$\ce{MnO2}$和浓盐酸反应制取$\ce{Cl2}$：$\ce{MnO2 + 4HCl(浓) -> MnCl2 + Cl2 ^ + 2H2O}$。
（1）写出该反应的离子方程式；（4分）
（2）若使用$8.7\text{g}$ $\ce{MnO2}$，理论上可生成$\ce{Cl2}$多少升（标准状况）？（6分）
（3）被氧化的$\ce{HCl}$的物质的量是多少？（6分）

参考答案：
（1）$\ce{MnO2 + 4H+ + 2Cl- -> Mn^{2+} + Cl2 ^ + 2H2O}$（注意：浓盐酸写离子形式时$\ce{HCl}$拆开）
（2）$n(\ce{MnO2}) = 8.7 / 87 = 0.1\text{mol}$，$n(\ce{Cl2}) = 0.1\text{mol}$，$V(\ce{Cl2}) = 0.1\times22.4 = 2.24\text{L}$
（3）$4\text{mol}$ $\ce{HCl}$中有$2\text{mol}$被氧化生成$\ce{Cl2}$，所以$0.1\text{mol}$ $\ce{MnO2}$对应$0.2\text{mol}$ $\ce{HCl}$被氧化。
19.（16分）将一定量的$\ce{Na2CO3}$和$\ce{NaHCO3}$混合物加热至质量不再变化，称得残留固体质量减少了$6.2\text{g}$。取等质量的混合物溶于水，加入足量$\ce{CaCl2}$溶液，得到沉淀$10\text{g}$。
（1）写出混合物加热时发生反应的化学方程式；（4分）
（2）计算原混合物中$\ce{Na2CO3}$和$\ce{NaHCO3}$的物质的量各是多少？（12分）

参考答案：
（1）$\ce{2NaHCO3 ->[加热] Na2CO3 + CO2 ^ + H2O ^}$
（2）减少质量为$\ce{CO2 + H2O}$：$M = 44+18=62\text{g/mol}$，$n = 6.2/62 = 0.1\text{mol}$
$\therefore n(\ce{NaHCO3}) = 2\times0.1 = 0.2\text{mol}$
沉淀为$\ce{CaCO3}$：$n(\ce{CaCO3}) = 10/100 = 0.1\text{mol}$
$\ce{CO3^{2-}}$总量$= 0.1\text{mol}$，其中来自$\ce{NaHCO3}$加热生成的$\ce{Na2CO3}$为$0.1\text{mol}$
$\therefore$原混合物中$\ce{Na2CO3}$为$0.1-0.1=0\text{mol}$。
实际上，$\ce{NaHCO3}$加热生成的$\ce{Na2CO3}$为$0.1\text{mol}$，而沉淀总量中$\ce{CaCO3}$来自原$\ce{Na2CO3}$和加热生成的$\ce{Na2CO3}$。设原$\ce{Na2CO3}$为$x\text{mol}$：$x + 0.1 = 0.1$，$x=0$。
所以$\ce{Na2CO3}$为$0\text{mol}$，$\ce{NaHCO3}$为$0.2\text{mol}$。
