一、单选题（共10题，每题4分，共40分）
1. 牛顿第一定律指出（  ）
答案：C
2. 质量为$5\text{kg}$的物体，受到$F_1=10\text{N}$和$F_2=6\text{N}$两个力的作用，则加速度的最大值和最小值分别为（  ）
答案：A（$F_{\max}=16\text{N}$，$a_{\max}=16/5=3.2$；$F_{\min}=4\text{N}$，$a_{\min}=4/5=0.8$）
3. 一个物体受到两个共点力$F_1=3\text{N}$和$F_2=4\text{N}$的作用，保持$F_1$和$F_2$的夹角不变，将它们同时增大$2\text{N}$，则合力（  ）
答案：B
4. 一个力$F$分解为两个分力$F_1$和$F_2$，下列说法正确的是（  ）
答案：C（如夹角$120^\circ$，$F_1=F_2=F$）
5. 质量为$2\text{kg}$的物体，在$F=10\text{N}$的水平拉力作用下沿水平面运动，物体与水平面间的动摩擦因数为$0.2$，则物体的加速度为（$g=10\text{m/s}^2$）（  ）
答案：D（$f=\mu mg=4\text{N}$，$F_{\text{合}}=F-f=6\text{N}$，$a=6/2=3$）
6. 物体在$F$作用下做匀加速直线运动，若$F$逐渐减小，则物体的加速度和速度变化情况是（  ）
答案：A（$F$减小但仍有合力，速度仍增大，但增加变慢）
7. 静止在光滑水平面上的物体，受到一个逐渐减小的水平拉力，则物体（  ）
答案：B
8. 人站在地面上，地面对人的支持力和人对地面的压力是（  ）
答案：C
9. 电梯中放一弹簧秤，秤上挂一重物。当电梯匀加速下降时，弹簧秤的示数（  ）
答案：A（失重）
10. 质量为$m$的物体放在粗糙水平面上，用水平力$F$拉动物体，产生的加速度为$a$。若将水平力改为$2F$，加速度（  ）
答案：D（$a=(F-f)/m$，$2F$时$f$不变，$a'=(2F-f)/m > 2(F-f)/m = 2a$）
二、多选题（共2题，每题5分，共10分）
11. 下列说法正确的是（  ）
答案：A、B、D
12. 一物体从静止开始做匀加速直线运动，第2秒内的位移为$6\text{m}$，则（  ）
答案：A、C（第2秒内位移$\Delta x = \frac12 a(2^2-1^2) = \frac32 a = 6$，$a=4$；$v_2=at=8$；前2秒$x=8$）
三、填空题（共3题，每题6分，共18分）
13. 牛顿第二定律的表达式为$F_{\text{合}} = $______，其中力的单位牛顿（N）用基本单位表示为______。

答案：$ma$；$\text{kg}\cdot\text{m/s}^2$
14. 作用力与反作用力大小______、方向______、作用在______物体上。

答案：相等；相反；不同（两个）
15. 质量为$50\text{kg}$的人站在升降机中，升降机以$2\text{m/s}^2$的加速度匀加速上升，人对升降机的压力为______$\text{N}$（$g=10$）。

答案：600（$F_N=m(g+a)=50\times12=600\text{N}$）
四、计算题（共4题，共32分）
16.（8分）一个物体质量为$20\text{kg}$，放在光滑水平面上，受水平力$F$作用从静止开始运动，$3\text{s}$末速度达到$6\text{m/s}$。求水平力$F$的大小。

参考答案：
$a = \Delta v / \Delta t = 6/3 = 2\text{m/s}^2$，$F = ma = 20\times2 = 40\text{N}$
17.（8分）质量为$10\text{kg}$的物体在$F=50\text{N}$的水平拉力作用下，沿水平面做匀加速直线运动，物体与水平面间的动摩擦因数为$0.3$，求物体的加速度大小。

参考答案：
$f = \mu mg = 0.3\times10\times10 = 30\text{N}$，$F_{\text{合}} = F - f = 50-30=20\text{N}$，$a = F_{\text{合}}/m = 20/10 = 2\text{m/s}^2$
18.（8分）质量为$5\text{kg}$的物体静止在水平面上，用水平力$F=15\text{N}$拉时物体恰能做匀速直线运动。若改用$F=25\text{N}$的力拉，物体的加速度多大？

参考答案：
匀速时$f = F = 15\text{N}$，$F'=25\text{N}$时$F_{\text{合}} = 25-15 = 10\text{N}$，$a = 10/5 = 2\text{m/s}^2$
19.（8分）一个滑雪者质量为$60\text{kg}$，从静止开始沿倾角$30^\circ$的斜坡滑下，滑行$100\text{m}$后速度达到$20\text{m/s}$，求滑雪者所受的阻力大小。（$g=10\text{m/s}^2$，$\sin30^\circ=0.5$）

参考答案：
$v^2=2ax$，$400=2a\times100$，$a=2\text{m/s}^2$
$mg\sin\theta - f = ma$，$60\times10\times0.5 - f = 60\times2$，$300 - f = 120$，$f = 180\text{N}$
