## 第一章 — 运动的描述

### 1.1 质点 参考系
- 质点的概念（理想化模型，忽略形状和大小）
- 参考系的选择与运动的相对性

### 1.2 时间 位移
- 时刻与时间间隔（区分 t 与 Δt）
- 位移（矢量）与路程（标量）
- 矢量的表示：方向 + 大小

### 1.3 位置变化快慢的描述——速度
- 平均速度 v̄ = Δx/Δt
- 瞬时速度（极限思想，Δt → 0）
- 速率（标量）与速度（矢量）的区别

### 1.4 速度变化快慢的描述——加速度
- 加速度 a = Δv/Δt（矢量，方向与 Δv 相同）
- **关键**：a 的正负不代表大小，只代表方向
- 加速/减速的判断（a 与 v 同向则加速，反向则减速）

### 实验：用打点计时器测速度
- 电磁打点计时器（～50 Hz，T = 0.02 s）
- 纸带分析与瞬时速度的计算

### 常见题型
- 平均速度与瞬时速度的辨析
- 加速度的计算与方向判断
- x-t 图与 v-t 图的识别与转换

## 第二章 — 匀变速直线运动的研究

### 2.1 实验：探究小车速度随时间变化的规律
- 纸带数据处理：逐差法求加速度
- v-t 图象：一条倾斜直线 ⇒ 匀变速直线运动

### 2.2 匀变速直线运动的速度与时间的关系
- v = v₀ + at
- v-t 图线：截距 = v₀，斜率 = a

### 2.3 匀变速直线运动的位移与时间的关系
- x = v₀t + ½at²
- v-t 图面积 = 位移
- x-t 图（抛物线）的识别

### 2.4 自由落体运动
- 条件：只受重力，初速度为零
- 重力加速度 g ≈ 9.8 m/s²（地点不同略有差异）
- 公式：v = gt，h = ½gt²，v² = 2gh

### 2.5 匀变速直线运动推论（补充）
- **推论 1**：v̄ = (v₀ + v)/2 = v_(t/2)
- **推论 2**：匀变速直线运动中，相邻相等时间间隔内位移差 Δx = aT²
- **推论 3**：v² − v₀² = 2ax
- **比例推论**：初速为零的匀加速，连续相等时间的位移比 1:3:5:⋯

### 常见题型
- 多过程问题（刹车类、先加速后匀速等）
- 追及相遇问题（临界条件：速度相等时距离最值）
- 自由落体与竖直上抛
- 纸带数据处理（逐差法）

## 第三章 — 相互作用——力

### 3.1 重力与弹力
- **重力**：G = mg，重心（与质量分布和形状有关）
- **弹力**：产生条件（接触 + 形变），方向（与形变方向相反）
- 常见弹力：支持力、压力、拉力（绳：沿绳收缩方向）
- 胡克定律：F = kx（弹簧弹力与形变量成正比）
- 弹力有无的判断（假设法/状态法）

### 3.2 摩擦力
- **滑动摩擦力**：f = μF_N（方向与相对运动方向相反）
- **静摩擦力**：0 ≤ f ≤ f_max（方向与相对运动趋势方向相反）
- 摩擦力的"突变"问题（静→动）

### 3.3 牛顿第三定律
- 作用力与反作用力：等大、反向、同线、异体、同时
- 与平衡力的区别（作用对象不同）

### 3.4 力的合成与分解
- **平行四边形定则**（矢量运算核心）
- 合力与分力的等效替代关系
- 力的正交分解法（建系原则：让尽量多的力在轴上）
- 求合力范围：|F₁ − F₂| ≤ F合 ≤ F₁ + F₂

### 3.5 共点力的平衡
- 平衡条件：F合 = 0（在 x、y 方向投影：∑Fₓ = 0，∑Fᵧ = 0）
- 三力平衡：任意两力的合力与第三力等大反向
- 动态平衡分析法：解析法、图解法

### 常见题型
- 弹力方向的判断（杆/绳/弹簧的差异性）
- 摩擦力的计算（静摩擦力的范围）
- 受力分析（隔离法、整体法）
- 正交分解与动态平衡

## 第四章 — 运动和力的关系

### 4.1 牛顿第一定律
- 内容：物体具有惯性，不受力时保持匀速直线或静止
- 惯性（质量是惯性大小的唯一量度）
- 伽利略理想斜面实验（实验+推理，否定了力是维持运动的原因）

### 4.2 实验：探究加速度与力、质量的关系
- 控制变量法
- 实验方案（槽码法/气垫导轨）
- 数据处理：a-F 图、a-1/m 图

### 4.3 牛顿第二定律
- F = ma（矢量性、瞬时性、同向性、因果性）
- 合力产生加速度，a 的方向与 F合 一致
- 应用步骤：受力分析 → 求合力 → 列方程

### 4.4 力学单位制
- 基本单位（m, kg, s, A, K, mol, cd）
- 导出单位（N = kg·m/s²）
- 量纲分析（检查公式正确性）

### 4.5 牛顿运动定律的应用
- **已知力求运动**（求 a → 运动学公式）
- **已知运动求力**（运动学求 a → 合力 → 某个力）
- **两类基本问题**的解题框架

### 4.6 超重和失重
- **超重**：F_N > G（加速度向上，加速上升或减速下降）
- **失重**：F_N < G（加速度向下，减速上升或加速下降）
- 完全失重：a = g（如自由落体、绕地卫星）

### 常见题型
- 连接体问题（整体法与隔离法结合）
- 临界问题（"恰好"、"最大"、"最小"关键词）
- 传送带问题与板块模型
- 超失重现象的判断与计算
