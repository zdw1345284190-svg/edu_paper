20. （12分）将 $\pu{2.7 g}$ 铝粉完全溶解于 $\pu{100 mL}$ $\pu{3 mol·L-1}$ 的 $\ce{HCl}$ 溶液中。
（1）写出反应的化学方程式，并计算生成 $\ce{H2}$ 的体积（标准状况）。
（2）若向反应后的溶液中逐滴加入 $\pu{2 mol·L-1}$ 的 $\ce{NaOH}$ 溶液，要使生成的沉淀质量最大，需要 $\ce{NaOH}$ 溶液多少毫升？
参考答案：
（1）$\ce{2Al + 6HCl -> 2AlCl3 + 3H2 ^}$
$n(\ce{Al}) = \pu{2.7 g} / \pu{27 g·mol-1} = \pu{0.1 mol}$
$n(\ce{HCl}) = \pu{0.1 L} \times \pu{3 mol·L-1} = \pu{0.3 mol}$
铝与 HCl 恰好完全反应（$0.1\ \text{mol Al}$ 需 $\pu{0.3 mol HCl}$）。
$n(\ce{H2}) = \pu{0.15 mol}$，$V(\ce{H2}) = \pu{0.15 mol} \times \pu{22.4 L·mol-1} = \pu{3.36 L}$。

（2）沉淀最大时，溶液中溶质为 $\ce{NaCl}$，
$n(\ce{NaOH}) = n(\ce{HCl}) = \pu{0.3 mol}$，
$V(\ce{NaOH}) = \pu{0.3 mol} / \pu{2 mol·L-1} = \pu{0.15 L} = \pu{150 mL}$。
21. （12分）将 $\pu{7.8 g}$ $\ce{Na2O2}$ 投入到 $\pu{100 g}$ 水中，充分反应后：
（1）写出反应的化学方程式，并计算生成 $\ce{O2}$ 的质量。
（2）将所得溶液稀释至 $\pu{500 mL}$，求 $\ce{NaOH}$ 的物质的量浓度。
（3）向稀释后的溶液中加入足量 $\ce{AlCl3}$ 溶液，计算生成 $\ce{Al(OH)3}$ 沉淀的质量。
参考答案：
（1）$\ce{2Na2O2 + 2H2O -> 4NaOH + O2 ^}$
$n(\ce{Na2O2}) = \pu{7.8 g} / \pu{78 g·mol-1} = \pu{0.1 mol}$
$n(\ce{O2}) = \pu{0.05 mol}$，$m(\ce{O2}) = \pu{0.05 mol} \times \pu{32 g·mol-1} = \pu{1.6 g}$。

（2）$n(\ce{NaOH}) = \pu{0.2 mol}$，$c(\ce{NaOH}) = \pu{0.2 mol} / \pu{0.5 L} = \pu{0.4 mol·L-1}$。

（3）$\ce{AlCl3 + 3NaOH -> Al(OH)3 v + 3NaCl}$
$n(\ce{Al(OH)3}) = \frac{1}{3} n(\ce{NaOH}) = \pu{0.2 mol} / 3 \approx \pu{0.0667 mol}$
$m(\ce{Al(OH)3}) = \pu{0.0667 mol} \times \pu{78 g·mol-1} \approx \pu{5.20 g}$。
22. （12分）镁铝合金 $\pu{5.1 g}$ 完全溶于 $\pu{100 mL}$ $\pu{5 mol·L-1}$ 的盐酸中，充分反应后生成 $\pu{5.6 L}$ 氢气（标准状况）。
（1）计算该合金中镁和铝的物质的量之比。
（2）若向反应后的溶液中加入 $\pu{2 mol·L-1}$ 的 $\ce{NaOH}$ 溶液至沉淀不再变化，求所需 $\ce{NaOH}$ 溶液的体积。
参考答案：
（1）设 $n(\ce{Mg}) = x\ \text{mol}$，$n(\ce{Al}) = y\ \text{mol}$。
质量：$24x + 27y = 5.1$
氢气：$\ce{Mg + 2HCl -> MgCl2 + H2 ^}$，$\ce{2Al + 6HCl -> 2AlCl3 + 3H2 ^}$
$n(\ce{H2}) = x + 1.5y = \pu{5.6 L} / \pu{22.4 L·mol-1} = \pu{0.25 mol}$
解得 $x = 0.1$，$y = 0.1$，$n(\ce{Mg}) : n(\ce{Al}) = 1:1$。

（2）沉淀不再变化时，溶液中溶质为 $\ce{NaCl}$ 和 $\ce{Na[Al(OH)4]}$。
$n(\ce{Cl-}) = n(\ce{HCl}) = \pu{0.1 L} \times \pu{5 mol·L-1} = \pu{0.5 mol}$
$n(\ce{NaCl}) = n(\ce{Cl-}) = \pu{0.5 mol}$
$n(\ce{Al}) = \pu{0.1 mol}$，$n(\ce{Na[Al(OH)4]}) = \pu{0.1 mol}$
$n(\ce{NaOH}) = n(\ce{NaCl}) + n(\ce{Na[Al(OH)4]}) = \pu{0.5 mol} + \pu{0.1 mol} = \pu{0.6 mol}$
$V(\ce{NaOH}) = \pu{0.6 mol} / \pu{2 mol·L-1} = \pu{0.3 L} = \pu{300 mL}$。
