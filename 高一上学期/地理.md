## 第一章 — 宇宙中的地球

### 1.1 地球的宇宙环境
- **天体系统层次**：
  ```
  地月系 → 太阳系 → 银河系 → 本星系群 → 可观测宇宙
  ```
- **太阳系八大行星**（距太阳由近到远）：
  - 水金地火（类地行星）| 木土（巨行星）| 天王海王（远日行星）
  - 小行星带位于火星和木星之间
- **地球存在生命的条件**：
  - 外部条件：稳定的光照、安全的宇宙环境
  - 内部条件：适宜的温度（日地距离适中）、液态水、适宜大气（体积质量适中）

### 1.2 太阳对地球的影响
- **太阳辐射**：
  - 能量来源：太阳内部核聚变反应（H → He）
  - 影响：直接提供光热资源、驱动大气和水循环、为人类提供化石能源（间接）
  - 分布规律：纬度越低太阳辐射越强；海拔越高太阳辐射越强；晴天多则强
- **太阳活动**：
  - 类型：太阳黑子（光球层）、耀斑和日珥（色球层）、太阳风（日冕层）
  - 周期：约 11 年
  - 影响：扰动电离层（影响无线电短波通信）、产生磁暴和极光、与自然灾害相关

### 1.3 地球的历史
- **地质年代表**：
  | 代 | 纪 | 主要特征 |
  |---|----|---------|
  | 太古宙 | — | 原始生命出现（蓝藻），大气缺氧 |
  | 元古宙 | — | 蓝藻大爆发，氧气增加 |
  | 古生代 | 寒武—奥陶—志留—泥盆—石炭—二叠 | "寒武纪生命大爆发"，脊椎动物（鱼类→两栖类），蕨类植物繁盛，末期最大灭绝 |
  | 中生代 | 三叠—侏罗—白垩 | 爬行动物（恐龙）繁盛，裸子植物为主，末期恐龙灭绝 |
  | 新生代 | 古近—新近—第四 | 哺乳动物大发展，被子植物繁盛，人类出现（第四纪）|
- **重要事件**：
  - 联合古陆（泛大陆）的形成与解体
  - 喜马拉雅运动（新生代，青藏高原隆起）

### 1.4 地球的圈层结构
- **内部圈层**（莫霍面、古登堡面为分界）：
  ```
  地壳（0-33 km，平均 17 km，大陆厚大洋薄）
    ↓ 莫霍界面
  地幔（33-2900 km，上地幔顶部存在软流层——岩浆发源地）
    ↓ 古登堡界面
  地核（2900-6371 km，外核液体，内核固体）
  ```
- **岩石圈** = 地壳 + 上地幔顶部（软流层之上）—— 注意与地壳的区别
- **外部圈层**：大气圈、水圈、生物圈（最活跃的圈层，界线不确定）

### 常见题型
- 生命存在条件的分析
- 太阳辐射分布的影响因素
- 地质事件与年代对应
- 圈层结构与地震波特征（P 波/S 波在不同介质中的传播）

## 第二章 — 地球上的大气

### 2.1 大气的组成和垂直分层
- **组成**：N₂（78%）+ O₂（21%）+ Ar + CO₂ + O₃ + 水汽 + 杂质
- **垂直分层**（自下而上）：
  | 层 | 高度 | 温度变化 | 特征 |
  |---|---|---------|------|
  | 对流层 | 8-18 km | 随高度递减（+6.5℃/km） | 天气现象复杂，对流运动显著 |
  | 平流层 | 至 50 km | 随高度递增 | 臭氧层，适合飞机飞行 |
  | 高层大气 | 至 2000+ km | 先降后升 | 电离层反射无线电波 |

### 2.2 大气受热过程
- **过程**（"太阳暖大地、大地暖大气、大气返大地"）：
  1. 太阳短波辐射穿过大气 → 地面吸收（大部分）
  2. 地面长波辐射加热大气（近地面大气的直接热源）
  3. 大气逆辐射将热量返还地面（保温作用）
- **应用**：
  - 阴天昼夜温差小（白天大气削弱，夜间保温）
  - 青藏高原昼夜温差大（白天削弱少，夜间保温弱）
  - 温室效应：CO₂ 等温室气体吸收地面长波辐射增强

### 2.3 大气运动
- **热力环流**（大气运动最简单形式）：
  ```
  受热多 → 气流上升 → 近地面低压 → 气流从高压流向低压
  受热少 → 气流下沉 → 近地面高压
  ```
- **常见热力环流**：
  - 海陆风（白天海风，夜间陆风）
  - 山谷风（白天谷风，夜间山风）
  - 城市热岛效应（市区与郊区之间形成城市风）

### 2.4 大气的水平运动——风
- **受力分析**：
  - 水平气压梯度力（**根本原因**、决定风向与风速大小）
  - 地转偏向力（垂直于风向，只改变方向不改变大小）
  - 摩擦力（减小风速，近地面才有）
- **近地面风**：与等压线斜交（三力平衡）
- **高空风**：与等压线平行（二力平衡）

### 常见题型
- 大气受热过程与昼夜温差分析
- 热力环流的形成与等压面弯曲
- 风向判断与等压线图判读

## 第三章 — 地球上的水

### 3.1 水循环
- **类型**：
  - 海上内循环（蒸发→降水，水量最大）
  - 海陆间循环（**最重要**，更新陆地淡水资源）
  - 陆地内循环（内陆地区）
- **环节**：蒸发/蒸腾 → 水汽输送 → 降水 → 地表径流 → 下渗 → 地下径流
- **意义**：
  - 维持全球水量动态平衡
  - 促进能量交换与物质迁移
  - 塑造地表形态
  - 更新陆地淡水资源

### 3.2 海水的性质
- **温度**：
  - 空间分布：低纬＞高纬，表层＞深层
  - 时间分布：夏季＞冬季
  - 影响因素：太阳辐射（首要）、洋流
- **盐度**：
  - 世界大洋平均盐度 35‰
  - 分布规律：从副热带海区向两侧递减（副热带＞赤道＞高纬）
  - 影响因素：蒸发量 vs 降水量、河流注入、洋流
  - 红海盐度最高（蒸发强、降水少、封闭），波罗的海最低
- **密度**：
  - 从赤道向两极递增
  - 影响因素：温度（主要）、盐度、深度

### 3.3 海水的运动
- **海浪**：风浪、涌浪、海啸（地震/火山引发）
- **潮汐**：月球和太阳引力引起，周期 24 小时 50 分，一天两次涨落
  - 大潮（日地月一线，初一/十五）与小潮
  - 应用：潮汐发电、港口航运
- **洋流**（本章铺垫，高二重点展开）：
  - 按性质分：暖流（低纬→高纬）与寒流（高纬→低纬）
  - 按成因分：风海流、密度流、补偿流

### 常见题型
- 水循环环节与人类活动影响
- 海水盐度/温度分布曲线判读
- 潮汐的计算与应用

## 第四章 — 地貌

### 4.1 常见地貌类型
- **流水地貌**：
  - 侵蚀：V 形谷、峡谷、瀑布、喀斯特地貌（溶洞、石林）
  - 堆积：冲积扇（出山口）、冲积平原、三角洲（入海口）
- **风成地貌**：
  - 侵蚀：风蚀蘑菇、雅丹地貌
  - 堆积：沙丘（新月形沙丘，背风坡陡、迎风坡缓）
- **海岸地貌**：
  - 侵蚀：海蚀崖、海蚀柱、海蚀洞
  - 堆积：沙滩、沙嘴、潟湖
- **冰川地貌**：
  - 侵蚀：U 形谷、角峰、冰斗
  - 堆积：冰碛丘陵、漂砾

### 4.2 地貌的观察
- 观察顺序：宏观→微观，由远及近
- 观察内容：高度（绝对/相对）、坡度、坡向、形状

### 常见题型
- 等高线地形图判读（山顶、鞍部、山谷、山脊、陡崖）
- 河流地貌对聚落/交通的影响
- 内外力作用与地貌成因分析

## 第五章 — 植被与土壤

### 5.1 植被
- **植被类型**：
  | 类型 | 分布 | 特征 |
  |------|------|------|
  | 热带雨林 | 赤道附近 | 高大茂密，四季常绿，板状根、茎花 |
  | 常绿阔叶林 | 亚热带 | 终年常绿，革质叶片 |
  | 落叶阔叶林 | 温带 | 春季发芽，秋冬落叶 |
  | 针叶林 | 寒温带 | 耐寒，针状叶（泰加林）|
  | 草原 | 半干旱区 | 草本为主，根系发达 |
  | 荒漠 | 干旱区 | 耐旱，根系深，叶小或退化为刺 |
- **与环境的关系**：植被类型由气候（水热条件）决定
  - 垂直地带性：山地从山麓到山顶植被变化模拟纬度变化

### 5.2 土壤
- **组成**：矿物质（45%）+ 有机质（5%）+ 空气（25%）+ 水（25%）
- **形成因素**：
  ```
  母质（基础） + 气候（决定性） + 生物（核心） + 地形 + 时间 + 人类活动
  ```
- **土壤剖面**（从上到下）：
  - 有机层（O）
  - 腐殖质层/表土层（A）— 颜色深
  - 淋溶层（E）
  - 淀积层/心土层（B）— 黏粒/矿物质积累
  - 母质层（C）
  - 基岩层（R）
- **我国代表性土壤**：东北黑土（有机质高）、南方红壤（淋溶强，酸性）
- **土壤保护**：轮作、休耕、秸秆还田、增施有机肥

### 常见题型
- 植被类型与气候类型的对应关系
- 土壤剖面各层特点
- 影响土壤形成的因素分析

## 第六章 — 自然灾害

### 6.1 气象灾害
- **洪涝**：
  - 成因：降水集中、地势低洼、河道淤塞、排水不畅
  - 防御：工程措施（堤坝/水库）、非工程措施（预警/保险）
- **干旱**：
  - 特点：持续时间长、影响范围广
  - 防御：节水灌溉、跨流域调水、调整种植结构
- **台风（热带气旋）**：
  - 结构：台风眼（气压最低，风平浪静）→ 旋涡风雨区 → 外围大风区
  - 影响：强风、暴雨、风暴潮
  - 防御：加强监测预警、提高建筑抗风能力
- **寒潮**：大范围强降温（24 h 降温 ≥ 8℃并低于 4℃）

### 6.2 地质灾害
- **地震**：
  - 震级（一次地震只有一个震级）vs 烈度（受震级、震源深度、地质构造、建筑物质量等影响）
  - 主要分布：环太平洋地震带、地中海-喜马拉雅地震带
  - 逃生：伏地、遮挡、手抓牢
- **滑坡**：斜坡上的岩体/土体沿滑动面整体下滑（多雨地区）
- **泥石流**：含大量泥沙石块的洪流（沟谷中，短时暴雨激发）
  - 逃生：向垂直于泥石流流向的高处跑
- **地质灾害的关联性**：地震 → 滑坡/泥石流（次生灾害）

### 6.3 防灾减灾
- 监测预警系统
- 工程措施与生物措施
- 提高公众防灾意识

### 常见题型
- 自然灾害的成因分析（自然+人为）
- 灾害分布规律与地理环境的关系
- 防灾减灾措施的合理选择
- 灾害关联链的分析

## 自然地理要素关联总结

```
太阳辐射
    ↓
  大气 ←→ 水
    ↓      ↓
  岩石 ←→ 生物（土壤）
```

各自然地理要素相互影响、相互制约，构成统一的整体（**整体性原理**）——这也是地理学科的核心思维方式。
