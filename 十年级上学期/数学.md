## 第二章 — 一元二次函数、方程和不等式

### 2.1 等式性质与不等式性质
- 实数比较：a > b ⇔ a − b > 0
- 不等式的基本性质（传递性、可加性、可乘性、同向可加等）
- 证明方法：作差法、作商法

### 2.2 基本不等式
- √(ab) ≤ (a + b)/2（a, b ≥ 0）
- 一正二定三相等
- 最值应用：积定和最小，和定积最大

### 2.3 二次函数与一元二次方程、不等式
- ax² + bx + c > 0（< 0）的解集
- 数形结合（判别式 Δ、开口方向、根）
- 含参数不等式的讨论
- 三个"二次"关系：二次函数 ↔ 一元二次方程 ↔ 一元二次不等式

### 常见题型
- 利用基本不等式求最值
- 一元二次不等式恒成立问题
- 分式不等式与高次不等式

## 第五章 — 三角函数

### 5.1 任意角和弧度制
- 正角、负角、零角，终边相同的角
- 弧度制：180° = π rad
- 扇形弧长与面积公式

### 5.2 三角函数的概念
- 单位圆定义：sin α, cos α, tan α
- 同角三角函数关系：sin²α + cos²α = 1, tan α = sin α/cos α
- 各象限符号规律（一全正，二正弦，三正切，四余弦）

### 5.3 诱导公式
- 公式二 ~ 公式六（转换 ±α, π±α, 2π−α）
- 口诀：奇变偶不变，符号看象限

### 5.4 三角函数的图象与性质
- **y = sin x**：定义域 R，值域 [−1,1]，周期 2π
- **y = cos x**：定义域 R，值域 [−1,1]，周期 2π
- **y = tan x**：定义域 x ≠ π/2 + kπ，周期 π
- 五点作图法

### 5.5 三角恒等变换
- 和角/差角公式
- 倍角公式
- 辅助角公式 a sin x + b cos x

### 5.6 函数 y = A sin(ωx + φ)
- 振幅 A、周期 T = 2π/|ω|、相位 ωx + φ、初相 φ
- 平移与伸缩变换
- 实际应用（简谐运动、潮汐等）

### 5.7 三角函数的应用
