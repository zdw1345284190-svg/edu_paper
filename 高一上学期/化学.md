## 第一章 — 物质及其变化

### 1.1 物质的分类及转化
- **分类方法**：树状分类法、交叉分类法
- **常见分类**：
  - 纯净物 vs 混合物
  - 单质 vs 化合物
  - 氧化物（酸性/碱性/两性/不成盐）
  - 酸（一元/二元）、碱（一元/多元）、盐（正盐/酸式盐/碱式盐）
- **物质的转化**：金属 → 碱性氧化物 → 碱 → 盐的转化链
- **分散系**：溶液、胶体、浊液
  - 丁达尔效应（胶体的特征现象）
  - 胶体的制备（Fe(OH)₃ 胶体）

### 1.2 离子反应
- **电解质与非电解质**（区分标准：水溶液或熔融下能否导电）
- **强电解质 vs 弱电解质**（完全电离 vs 部分电离）
- **离子方程式书写**：
  - 写 → 拆（强酸、强碱、可溶盐拆）→ 删 → 查
  - 常见不可拆：单质、气体、沉淀、弱电解质（H₂O、弱酸、弱碱）、氧化物
- **离子共存问题**：
  - 生成沉淀、气体、弱电解质、发生氧化还原 → 不能共存

### 1.3 氧化还原反应
- **特征**：化合价变化（判据）
- **本质**：电子转移（得失或偏移）
- **基本概念**：
  - 氧化剂 → 得电子 → 化合价降低 → 被还原 → 还原产物
  - 还原剂 → 失电子 → 化合价升高 → 被氧化 → 氧化产物
  - 口诀："升失氧、降得还"
- **双线桥法 vs 单线桥法**表示电子转移
- **常见氧化剂与还原剂**：
  - 氧化剂：O₂、Cl₂、浓 H₂SO₄、HNO₃、KMnO₄、Fe³⁺
  - 还原剂：金属单质、C、CO、H₂、I⁻、Fe²⁺

### 常见题型
- 离子共存判断
- 离子方程式正误判断
- 氧化性/还原性强弱比较
- 氧化还原反应电子转移数计算

## 第二章 — 海水中的重要元素——钠和氯

### 2.1 钠及其化合物
- **钠的物理性质**：银白色、质软、密度 0.97 g/cm³（比水小比煤油大）、熔点低
- **钠的化学性质（钠的"四个一"）**：
  - 与 O₂ 反应：常温 Na₂O（白色），加热 Na₂O₂（淡黄色）
  - 与 H₂O 反应：2Na + 2H₂O = 2NaOH + H₂↑（浮熔游响红）
  - 与酸/醇反应
- **钠的氧化物**：
  - Na₂O（碱性氧化物）、Na₂O₂（过氧化物，强氧化性，与 H₂O/CO₂ 反应放 O₂）
- **碳酸钠与碳酸氢钠**：
  - Na₂CO₃（纯碱、苏打）与 NaHCO₃（小苏打）
  - 热稳定性：Na₂CO₃ > NaHCO₃
  - 与酸反应速率：NaHCO₃ > Na₂CO₃
  - 相互转化：Na₂CO₃ →(CO₂+H₂O)→ NaHCO₃ →(加热)→ Na₂CO₃

### 2.2 氯及其化合物
- **氯气 Cl₂**：
  - 黄绿色、有刺激性气味、有毒、密度比空气大
  - 与金属（Na/Fe/Cu 等）反应 → 氯化物
  - 与 H₂ 反应：H₂ + Cl₂ —点燃→ 2HCl（苍白色火焰，瓶口白雾）
  - 与 H₂O 反应：Cl₂ + H₂O ⇌ HCl + HClO（氯水成分复杂）
  - 与碱反应：Cl₂ + 2NaOH = NaCl + NaClO + H₂O（漂白液）
  - **漂白粉**：2Cl₂ + 2Ca(OH)₂ = CaCl₂ + Ca(ClO)₂ + 2H₂O
    - 有效成分：Ca(ClO)₂
    - 漂白原理：Ca(ClO)₂ + CO₂ + H₂O = CaCO₃↓ + 2HClO
- **次氯酸 HClO**：弱酸性、强氧化性、漂白性、不稳定见光分解

### 2.3 物质的量
- **摩尔（mol）**：物质的量的单位（阿伏加德罗常数 N_A ≈ 6.02×10²³）
- **核心公式**：
  - n = N/N_A（微粒数 → 物质的量）
  - n = m/M（质量 → 物质的量）
  - n = V/V_m（气体体积 → 物质的量，标况 V_m = 22.4 L/mol）
  - n = cV（溶液浓度 → 物质的量）
- **气体摩尔体积**：标况（0℃，101 kPa）下，1 mol 任何气体 ≈ 22.4 L
- **物质的量浓度**：
  - c = n/V（定义式）
  - 浓溶液稀释：c₁V₁ = c₂V₂
  - **配制一定物质的量浓度溶液**：
    - 步骤：计算 → 称量/量取 → 溶解/稀释 → 转移 → 洗涤 → 定容 → 摇匀 → 装瓶
    - 关键仪器：容量瓶（使用前检漏）
    - 误差分析（俯视/仰视等对 c 的影响）

### 常见题型
- 阿伏加德罗常数 N_A 的判断（微粒数、电子转移数等）
- 气体摩尔体积的计算
- 溶液配制实验操作与误差分析
- 钠/氯及其化合物的性质综合

## 第三章 — 铁 金属材料

### 3.1 铁及其化合物
- **单质铁**：活泼金属、可被磁铁吸引
  - 与 O₂ 点燃：3Fe + 2O₂ —点燃→ Fe₃O₄
  - 与酸/盐溶液的置换反应（Fe + 2H⁺ = Fe²⁺ + H₂↑）
- **铁的氧化物**：FeO（黑色）、Fe₂O₃（红棕色）、Fe₃O₄（磁性黑色）
- **铁的氢氧化物**：
  - Fe(OH)₂（白色，易被氧化 → 灰绿色 → 红褐色 Fe(OH)₃）
  - Fe(OH)₃（红褐色，加热分解为 Fe₂O₃）
- **Fe²⁺ 与 Fe³⁺ 的检验与转化**：
  - Fe³⁺ + SCN⁻ → 血红色（特征检验）
  - Fe²⁺ →(氧化剂)→ Fe³⁺（Cl₂/H₂O₂/O₂）
  - Fe³⁺ →(还原剂)→ Fe²⁺（Fe/Cu/I⁻）
- **"铁三角"转化关系**：
  ```
      Fe²⁺ ←— Fe —→ Fe³⁺
       ↑         ↓
      Fe³⁺ ←—— Fe²⁺
  ```

### 3.2 金属材料
- **合金**：由两种或更多金属（或金属与非金属）熔合而成
  - 合金硬度 > 组分金属，熔点 < 组分金属
  - 常见合金：
    - 铁合金：生铁（碳 2%~4.3%）、钢（碳 0.03%~2%）
    - 铝合金：轻便、耐腐蚀
    - 铜合金：黄铜（Cu-Zn）、青铜（Cu-Sn）
- **铝及其化合物**（补充）：
  - Al 与 O₂ 形成致密 Al₂O₃ 保护膜
  - Al₂O₃ 与 Al(OH)₃ 的两性：
    - Al₂O₃ + 6H⁺ = 2Al³⁺ + 3H₂O
    - Al₂O₃ + 2OH⁻ = 2AlO₂⁻ + H₂O
  - Al(OH)₃ + 3H⁺ = Al³⁺ + 3H₂O
  - Al(OH)₃ + OH⁻ = AlO₂⁻ + 2H₂O

### 常见题型
- Fe²⁺/Fe³⁺ 的检验、转化与除杂
- 铁及其化合物的框图推断
- 金属与酸/碱反应的计算（得失电子守恒）
- 合金成分分析

## 第四章 — 物质结构 元素周期律

### 4.1 原子结构与元素周期表
- **原子构成**：质子(Z) + 中子(N) = 质量数 A（Z + N = A）
- **核素与同位素**：
  - 核素：一定质子数和一定中子数的一种原子
  - 同位素：质子数相同、中子数不同的核素互称（如 ¹H、²H、³H）
- **原子核外电子排布**：
  - 分层排布（K、L、M、N···），2n² 规律
  - 最外层电子数 ≤ 8（≤ 2 若 K 层为最外层）
- **元素周期表结构**：
  - 7 个周期（短周期 1-3，长周期 4-7）
  - 16 个族（7 主族 + 7 副族 + Ⅷ族 + 0 族）
  - 元素位置 = 周期（电子层数）+ 主族（最外层电子数）

### 4.2 元素周期律
- **核外电子排布**：同周期从左到右，最外层电子数递增
- **原子半径**：
  - 同周期从左到右：递减（核电荷增加，吸引力增强）
  - 同主族从上到下：递增（电子层数增加）
- **元素金属性与非金属性**：
  - 金属性（失电子能力）：同周期左 > 右，同族下 > 上
  - 非金属性（得电子能力）：同周期右 > 左，同族上 > 下
- **最高价氧化物对应水化物的酸碱性**：金属性越强 → 碱性越强；非金属性越强 → 酸性越强
- **气态氢化物的稳定性**：非金属性越强 → 氢化物越稳定

### 4.3 化学键
- **离子键**：阴阳离子间的静电作用（活泼金属 + 活泼非金属）
  - 离子化合物：含离子键的化合物（如 NaCl、MgO、NaOH）
- **共价键**：原子间共用电子对
  - 极性共价键：不同元素原子之间（如 H₂O 中的 H-O 键）
  - 非极性共价键：同种元素原子之间（如 Cl₂ 中的 Cl-Cl 键）
  - 共价化合物：只含共价键（如 HCl、CO₂、H₂SO₄）
- **分子间作用力**：
  - 范德华力（分子间普遍存在，影响熔沸点）
  - 氢键（F/O/N 与 H 之间，影响熔沸点与溶解度——不是化学键！）
- **化学键与物质变化**：
  - 化学变化中一定有旧的化学键断裂与新的化学键形成

### 常见题型
- 元素"位-构-性"综合推断题
- 粒子半径大小比较
- 化学键类型判断与电子式书写
- 元素周期律的应用（比较金属性/非金属性强弱）
