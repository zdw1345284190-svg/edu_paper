参考答案与解析

一、单项选择题（每题3分）

1.【A】 质点是理想化模型，实际不存在。能否看成质点取决于研究问题，与体积大小无关。研究地球公转时地球可看成质点。

2.【C】 乘客看到树木向后运动，是以自己或列车为参考系。

3.【D】 时刻对应时间点，时间间隔对应时间段。8:00是时刻，百米赛跑成绩10.2秒、运行4小时、休息10分钟均为时间间隔。

4.【A】 位移大小为起点到终点的直线距离。\(x = \sqrt{3^2 + 4^2} = 5\,\text{m}\)。

5.【B】 跑一圈回到起点，初末位置重合，位移为 0；路程为 400m。

6.【B】 平均速度 \(\bar{v} = \Delta x / \Delta t\)，是位移与时间的比值，方向与位移方向相同。

7.【A】 瞬时速度是矢量，速率是标量，A正确B错误。汽车速度计显示的是瞬时速率，C错误。瞬时速度不是平均速度，D错误。

8.【C】 加速度的负号只表示方向与正方向相反。加速还是减速要看 \(a\) 与 \(v\) 的方向关系，不是看 \(a\) 的符号。

9.【A】 \(a = 3\,\text{m/s}^2\) 表示速度每秒增加 3m/s（当 \(a\) 与 \(v\) 同向时）。

10.【B】 电磁打点计时器使用交流 6V 以下电源，频率 50Hz，周期 0.02s。

二、多项选择题（每题4分）

11.【B、C】 研究地球公转和火车平均速度时，物体的形状和大小可以忽略，能看作质点。研究自转和旋转时不能。

12.【A、B、D】 位移是矢量，路程是标量。单向直线运动时位移大小等于路程。位移大小不大于路程（可等于），C说"一定小于"错误。

13.【A、B、C】 加速度减小时，只要 \(a\) 与 \(v\) 同向，速度仍在增加（只是增加得慢了），D错误。

三、填空题（每题3分）

14.【能】 研究百米赛跑成绩时，关注的是整体用时，形状大小可以忽略。

15.【①④；②③】 时刻指某一瞬间（第2秒末、5:00），时间间隔指一段时间（前3秒、第4秒内）。

四、解答题

20.（8分）

(1) 位移大小：\(x = \sqrt{6^2 + 8^2} = 10\,\text{m}\)（2分），方向：东偏北，与正东方向夹角 \(\theta = \arctan(8/6) \approx 53^\circ\)（2分）

(2) 路程：\(s = 6 + 8 = 14\,\text{m}\)（2分）

(3) 平均速度：\(\bar{v} = x / t = 10 / 10 = 1\,\text{m/s}\)（2分）

21.（10分）

(1) 前2s内位移：\(x = 5 + 10 = 15\,\text{m}\)（1分），\(\bar{v} = 15/2 = 7.5\,\text{m/s}\)（3分）

(2) 第3s内位移为15m，平均速度 \(\bar{v} = 15/1 = 15\,\text{m/s}\)（3分）

(3) 不能判断（1分）。因为不知道每1s内的具体运动情况，可能是匀速、加速或变速，仅凭三段位移无法确定是否为匀变速（2分）。

22.（10分）

(1) 0–2s：\(a_1 = (6-2)/2 = 2\,\text{m/s}^2\)（3分）

(2) 4–6s：\(a_2 = (2-6)/2 = -2\,\text{m/s}^2\)（3分）

(3) 0–2s：\(a>0\) 且 \(v>0\)，\(a\) 与 \(v\) 同向，做加速运动（2分）
2–4s：速度不变，做匀速运动（1分）
4–6s：\(a<0\) 且 \(v>0\)，\(a\) 与 \(v\) 反向，做减速运动（1分）

23.（12分）

(1) 工作电压为交流 6V（1分），频率为 50Hz（1分）

(2) \(v_B = \overline{AC}/2T = (2.5+3.5) / (2 \times 0.1) = 6.0/0.2 = 0.30\,\text{m/s}\)（3分）

(3) \(v_C = \overline{BD}/2T = (3.5+4.5) / (2 \times 0.1) = 8.0/0.2 = 0.40\,\text{m/s}\)（3分）

(4) 逐差法：\(a = (v_C - v_B)/T = (0.40 - 0.30)/0.1 = 1.0\,\text{m/s}^2\)（4分）
或 \(a = (DE - AB) / (3T^2) = (5.5-2.5) / (3 \times 0.01) = 3.0/0.03 = 1.0\,\text{m/s}^2\)
