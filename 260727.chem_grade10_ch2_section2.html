一、单选题
1. C —— 氯气密度比空气大（约为空气的2.5倍），故C项"密度比空气小"错误。
2. B —— 氯气具有强氧化性，与铁反应生成 FeCl₃ 而非 FeCl₂。FeCl₂ 不能由 Cl₂ 与 Fe 直接化合得到。
3. A —— H₂ 在 Cl₂ 中燃烧发出苍白色火焰，生成的 HCl 与空气中水蒸气结合形成盐酸小液滴，产生白雾。
4. A —— Cl₂ 溶于水，部分与水反应，氯水呈浅黄绿色是因为其中含有 Cl₂ 分子。
5. C —— 反应中 Cl₂ 中的 Cl 化合价从 0 价分别变为 -1 价（NaCl）和 +1 价（NaClO），故 Cl₂ 既作氧化剂又作还原剂。
6. D —— HClO 不稳定，见光易分解（2HClO \(\xrightarrow{见光}\) 2HCl + O₂↑），故 D 项"见光稳定"错误。
7. A —— 漂白粉是 CaCl₂ 和 Ca(ClO)₂ 的混合物，有效成分是 Ca(ClO)₂（次氯酸钙）。
8. B —— 漂白粉在空气中与 CO₂ 和 H₂O 反应生成 HClO，HClO 见光分解，导致漂白粉失效。
9. C —— Cl₂ + H₂O ⇌ HCl + HClO 中，Cl 从 0 价分别变为 -1 价（HCl）和 +1 价（HClO），Cl₂ 既被氧化又被还原。
10. C —— A错，干燥 Cl₂ 无漂白性，起漂白作用的是 HClO；B错，Cl₂ 能与 Cu 反应生成 CuCl₂；C对，Cl₂ 与 Fe 生成 FeCl₃；D错，Cl₂ 是黄绿色气体。
二、多选题
11. A, B, C —— 新制氯水中含有的分子有 Cl₂、H₂O、HClO。O₂ 是 HClO 见光分解的产物，新制氯水中 O₂ 极少。
12. A, C, D —— A对，有效成分为 Ca(ClO)₂。B错，漂白作用是 Ca(ClO)₂ 与 CO₂、H₂O 反应生成的 HClO 发挥的。C对，空气中 CO₂ 和 H₂O 使漂白粉逐渐失效。D对，工业上用 Cl₂ 与石灰乳反应制漂白粉。
13. A, C, D —— A对，MnO₂ + 4HCl(浓) \(\xrightarrow{\triangle}\) MnCl₂ + Cl₂↑ + 2H₂O。B错，Cl₂ 密度比空气大，应用向上排空气法。C对，饱和食盐水可吸收 HCl 而 Cl₂ 在其中的溶解度很小。D对，Cl₂ 有毒，需在通风橱中操作。
三、填空题
14. HCl；HClO —— Cl₂ + H₂O ⇌ HCl + HClO（可逆反应，次氯酸为弱酸）。
15. NaCl —— Cl₂ + 2NaOH = NaCl + NaClO + H₂O，所得溶液称为漂白液。
16. Ca(ClO)₂（次氯酸钙） —— 漂白粉是 CaCl₂ 和 Ca(ClO)₂ 的混合物，其中有效成分为 Ca(ClO)₂。
17. 2HCl；O₂ —— 2HClO \(\xrightarrow{见光}\) 2HCl + O₂↑，HClO 不稳定，见光分解。
18. CaCl₂（氯化钙） —— 2Cl₂ + 2Ca(OH)₂ = CaCl₂ + Ca(ClO)₂ + 2H₂O，工业制漂白粉。
19. 2HClO —— Ca(ClO)₂ + CO₂ + H₂O = CaCO₃↓ + 2HClO，漂白粉的漂白原理。
四、解答题（参考解答）
20. （10分）
(1)（2分）氯气为黄绿色气体、有刺激性气味、有毒、密度比空气大（答出任意三条即可）。
(2)（2分）2Fe + 3Cl₂ \(\xrightarrow{点燃}\) 2FeCl₃（未写条件扣1分）。
(3)（3分）Cl₂ + H₂O ⇌ HCl + HClO（1分）。该反应中 Cl 元素化合价从 0 分别变为 -1 和 +1，Cl₂ 既作氧化剂又作还原剂（2分）。
(4)（3分）氯水显浅黄绿色是因为含有 Cl₂ 分子（1分）。滴入石蕊试液先变红，说明氯水中含 H⁺（酸性）（1分）；后褪色，说明氯水中含 HClO（漂白性）（1分）。
21. （10分）
(1)（3分）2Cl₂ + 2Ca(OH)₂ = CaCl₂ + Ca(ClO)₂ + 2H₂O（未写条件扣1分）。
(2)（2分）有效成分：Ca(ClO)₂（次氯酸钙）。漂白原理：Ca(ClO)₂ + CO₂ + H₂O = CaCO₃↓ + 2HClO（1分），生成的 HClO 具有强氧化性，起漂白消毒作用（1分）。
(3)（3分）漂白粉在空气中与 CO₂ 和 H₂O 反应生成的 HClO 不稳定（1分），见光易分解：2HClO \(\xrightarrow{见光}\) 2HCl + O₂↑（2分），导致漂白粉失效。
(4)（2分）新制氯水含 Cl₂、H₂O、HClO、H⁺、Cl⁻、ClO⁻ 等多种微粒（1分）；久置氯水由于 HClO 分解，变为稀盐酸，主要含 H⁺ 和 Cl⁻（1分）。
22. （10分）
(1)（2分）0；-1；还原；氧化（每个空0.5分）。
(2)（2分）-1（1分）；+1（1分）。
(3)（3分）1（或 1mol）。反应③中只有一半 Cl 被氧化，1 mol Cl₂ 参与反应转移 1 mol 电子。
(4)（3分）氧化产物：Ca(ClO)₂（1.5分，Cl 从 0→+1，被氧化）；还原产物：CaCl₂（1.5分，Cl 从 0→-1，被还原）。
23. （10分）
(1)（2分）Cl₂（氯气）。
(2)（2分）H⁺（氢离子，1分）；HClO（次氯酸，1分）。
(3)（3分）Cl⁻ + Ag⁺ = AgCl↓（或 Ag⁺ + Cl⁻ = AgCl↓，3分；写 AgNO₃ + HCl = AgCl↓ + HNO₃ 给1分）。
(4)（3分）2HClO \(\xrightarrow{见光}\) 2HCl + O₂↑（3分，未写条件扣1分）。HClO 见光分解，Cl₂ 不断与水反应被消耗，黄绿色褪去。
