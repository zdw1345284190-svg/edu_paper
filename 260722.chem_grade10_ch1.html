📖 参考答案与解析

一、单选题
1. B —— 液氯是纯净的Cl₂，盐酸是HCl水溶液（混合物），漂白粉是混合物，空气是混合物。
2. B —— 丁达尔效应是胶体的特征现象，Fe(OH)₃胶体可以产生丁达尔效应。
3. C —— 电解质是水溶液或熔融状态下能导电的化合物。铜是单质，蔗糖和乙醇是非电解质。
4. D —— A错，铁与盐酸生成Fe²⁺而非Fe³⁺；B错，电荷不守恒（Ag⁺系数应为2）；C错，CaCO₃难溶于水不能拆。
5. C —— A中H⁺+OH⁻→水；B中Ba²⁺+SO₄²⁻→沉淀；D中H⁺+CO₃²⁻→气体。
6. B —— 特征：化合价变化（升降）。本质：电子转移。
7. B —— Cl₂得电子，化合价降低（0→-1），是氧化剂。
8. C —— F₂与H₂O反应中，H₂O中的O从-2价升到0价生成O₂，水被氧化，作还原剂。
9. B —— 制备方法：FeCl₃饱和溶液滴入沸水中，继续煮沸至红褐色，停止加热。
10. B —— Fe²⁺→Fe³⁺化合价升高（+2→+3），需加氧化剂。A/C/D是化合价降低，需加还原剂。
二、多选题
11. B, C —— A错，胶体介稳，可以聚沉。B对，胶体能透过滤纸（不能透过半透膜）。C对。D错，本质区别是分散质粒子大小。
12. B, C, D —— A错，CaCO₃难溶于水不能拆，应写化学式。B正确（注意系数配平）。C正确。D正确。
13. A, B, D —— A对，氧化剂得电子被还原，发生还原反应。B对。C错（如3O₂→2O₃有单质但化合价不变，不是氧化还原）。D对，置换反应一定有化合价变化。
三、填空题
14. ③；④ —— NaCl是电解质（溶于水导电）；蔗糖是非电解质（水溶液和熔融都不导电）。盐酸是混合物，液氯和Cu是单质，不是电解质也不是非电解质。
15. 沸水；FeCl₃饱和溶液 —— FeCl₃ + 3H₂O \(\xrightarrow{沸水}\) Fe(OH)₃(胶体) + 3HCl
16. H（氢）；Cu（铜） —— H从0价升到+1价被氧化；Cu从+2价降到0价被还原。
17. KMnO₄；HCl —— KMnO₄中Mn从+7降到+2（得电子，氧化剂）；HCl中Cl从-1升到0（失电子，还原剂）。
18. ①④；②③ —— 强电解质：完全电离（强酸、强碱、大部分盐）。NaOH是强碱，HCl是强酸。CH₃COOH和H₂CO₃是弱酸，部分电离。
19. CO₃²⁻（碳酸根） —— CO₃²⁻ + 2H⁺ = CO₂↑ + H₂O，产生无色无味气体（CO₂）。
四、解答题（参考解答）
20. （8分）
树状分类图如下：
        Na（钠）——————————单质
       /
      /   Na₂O（氧化钠）——氧化物（碱性氧化物）
      |  /
物质—纯净物—化合物—NaOH（氢氧化钠）——碱（一元碱）
      |            \
      |             盐——Na₂CO₃（碳酸钠）——正盐
      |                \—NaHCO₃（碳酸氢钠）——酸式盐
      |                  \—NaCl（氯化钠）——正盐
21. （10分）
(1) CO₃²⁻ + 2H⁺ = CO₂↑ + H₂O（3分）
(2) Ba²⁺ + 2OH⁻ + 2H⁺ + SO₄²⁻ = BaSO₄↓ + 2H₂O（4分，注意OH⁻和H⁺系数均为2）
(3) Fe + 2Ag⁺ = Fe²⁺ + 2Ag（3分）
22. （10分）
(1) 双线桥分析：
  KMnO₄中Mn从+7→+2，得5e⁻×2 = 10e⁻（被还原）
  HCl中Cl从-1→0，失1e⁻×10 = 10e⁻（被氧化）
  电子转移总数为10e⁻，方向：从HCl中的Cl指向KMnO₄中的Mn。
(2) 氧化剂：KMnO₄；还原剂：HCl（2分）
(3) 5mol（3分）。KMnO₄中Mn从+7降到+2，每个KMnO₄得5e⁻，1mol得5mol e⁻。
23. （12分）
(1) CO₂（2分）
(2) Na₂CO₃（2分），CO₃²⁻ + 2H⁺ = CO₂↑ + H₂O（2分）
(3) Na₂SO₄（2分，BaCl₂检测SO₄²⁻，无明显现象说明不含SO₄²⁻）
(4) 一定含有Na₂CO₃，可能含有NaCl（4分，焰色黄色说明含Na⁺，但所有物质都含Na⁺，不能区分NaCl是否存在）
  综上：一定含Na₂CO₃，一定不含Na₂SO₄，NaCl无法确定。
