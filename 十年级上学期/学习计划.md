## 附：各科核心公式速查

### 数学
- 基本不等式：√(ab) ≤ (a+b)/2（a, b ≥ 0）
- 判别式：Δ = b² − 4ac
- 指数运算：a^m · a^n = a^(m+n)
- 对数运算：logₐ(MN) = logₐM + logₐN
- 诱导公式口诀：奇变偶不变，符号看象限
- 辅助角公式：a sin x + b cos x = √(a²+b²) sin(x+φ)

### 物理
- v = v₀ + at
- x = v₀t + ½at²
- v² − v₀² = 2ax
- Δx = aT²
- F = ma
- f = μF_N
- F = kx

### 化学
- n = N/N_A
- n = m/M
- n = V/V_m（标况 22.4 L/mol）
- n = cV
- c₁V₁ = c₂V₂

### 生物
- 肽键数 = 氨基酸数 − 肽链数
- 蛋白质 M = n × aa 平均 M − 18 × (n − m)
- A=T, G=C
- 净光合 = 总光合 − 呼吸消耗
