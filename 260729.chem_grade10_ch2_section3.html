高一化学（人教版必修第一册）

第二章   2.3 物质的量   单元检测卷
总分：100分    考试时间：45分钟    命题范围：第二章 2.3

一、单选题（共10题，每题3分，共30分）

每题只有一个选项符合题意。

1.
下列有关"物质的量"的说法，正确的是（　）
答案：B — 1 mol 任何微粒集合体所含微粒数与 0.012 kg 12C 所含碳原子数相同，约为 6.02×10²³ 个。A 错：物质的量单位是摩尔（mol），质量单位才是克。C 错：物质的量是描述微粒集合体的物理量，与质量是不同的概念。D 错：摩尔是物质的量的单位，物质的量本身才是七个基本物理量之一。
2.
阿伏加德罗常数（\(N_A\)）的数值约为（　）
答案：C — 阿伏加德罗常数 N_A ≈ 6.02×10²³ mol⁻¹，表示 1 mol 任何微粒所含的微粒数。A 错在指数偏小（×10²²），B 和 D 均错误。
3.
\(0.5\ \text{mol}\ \text{H}_2\text{O}\) 中所含的分子数约为（　）
答案：B — 由 n = N / N_A 得 N = n × N_A = 0.5 × 6.02×10²³ = 3.01×10²³（个）。A 是 10²² 数量级错误，C 对应 1 mol，D 对应 10 mol。
4.
\(18\ \text{g}\ \text{H}_2\text{O}\) 的物质的量为（　）（已知 H₂O 的摩尔质量为 18 g·mol⁻¹）
答案：D — 由 n = m / M 得 n(H₂O) = 18 g / 18 g·mol⁻¹ = 1 mol。A 错在 0.5（9 g 水），B 错在 2（36 g 水），C 错在 3（54 g 水）。
5.
标准状况（STP）下，1 mol O₂ 的体积约为（　）
答案：B — 标准状况（0°C，101 kPa）下，1 mol 任何气体（包括 O₂）的体积均约为 22.4 L。A 对应 0.5 mol，C 对应 1.5 mol，D 对应 2 mol。
6.
下列说法正确的是（　）
答案：C — 标准状况（0°C，101 kPa）下，1 mol 任何气体的体积均约为 22.4 L。A 错：H₂O 在标况下为非气态（冰或液态），不适用气体摩尔体积。B 错：常温常压（25°C，101 kPa）下气体摩尔体积约为 24.5 L/mol，不是 22.4 L/mol。D 错：H₂SO₄ 在标况下为液态，不适用气体摩尔体积。
7.
标准状况下，\(44.8\ \text{L}\ \text{CO}_2\) 的物质的量为（　）
答案：A — 由 n = V / V_m 得 n(CO₂) = 44.8 L / 22.4 L·mol⁻¹ = 2 mol。B 对应 22.4 L，C 对应 11.2 L，D 对应 89.6 L。
8.
将 0.1 mol NaCl 溶于水配成 500 mL 溶液，所得溶液的物质的量浓度为（　）
答案：D — c = n / V = 0.1 mol / 0.5 L = 0.2 mol·L⁻¹。注意 V 的单位应统一为升（L），500 mL = 0.5 L。A 错（0.1 对应体积为 1 L），B 错（0.5 对应 0.2 mol 溶质），C 错（1.0 对应 0.5 mol 溶质）。
9.
配制 100 mL 1.00 mol·L⁻¹ NaCl 溶液的正确步骤顺序是（　）
①计算   ②溶解   ③转移   ④称量   ⑤定容   ⑥洗涤   ⑦摇匀
答案：C — 配制一定物质的量浓度溶液的标准步骤：①计算 → ④称量 → ②溶解 → ③转移（移入容量瓶）→ ⑥洗涤（洗涤烧杯和玻璃棒，洗涤液一并转入容量瓶）→ ⑤定容 → ⑦摇匀。A 错在洗涤后定容的顺序（先洗涤后定容），B 错在计算后直接溶解（未称量），D 顺序混乱。
10.
下列说法正确的是（　）
答案：A — O₂ 的摩尔质量为 32 g·mol⁻¹，故 1 mol O₂ 质量为 32 g，标况下体积为 22.4 L。B 错：物质的量浓度是指 1 L 溶液（而非溶剂水）中所含溶质的物质的量。C 错：阿伏加德罗定律的表述为"相同分子数"，而非"相同原子数"（不同的气体分子含原子个数可能不同，如 O₂ 含 2 个原子，CO₂ 含 3 个原子）。D 错：将 40 g NaOH（1 mol）溶解于 1 L 水中，所得溶液体积不是 1 L，故浓度不是 1 mol·L⁻¹。

二、多选题（共3题，每题4分，共12分）

每题有多个选项符合题意。全对得4分，部分选对得2分，有错选得0分。

11.
设 \(N_A\) 表示阿伏加德罗常数的值，下列说法正确的有（　）
答案：A, B, D — A 对：1 mol H₂ 分子即含 N_A 个 H₂ 分子。B 对：1 个 H₂O 分子含 3 个原子（2H + 1O），故 1 mol H₂O 含 3N_A 个原子。C 错（典型陷阱）：标准状况下 H₂O 为液态或固态，不是气体，不能用 22.4 L/mol。D 对：Na⁺ 原子序数 11，失去 1 个电子后剩余 10 个电子，故 1 mol Na⁺ 含 10N_A 个电子。
12.
配制一定物质的量浓度的 NaOH 溶液时，下列操作会导致所配溶液浓度偏低的有（　）
答案：A, C, D — A 对：NaOH 吸水潮解导致实际称得溶质质量偏小，n 偏小→c 偏低。B 错：定容时俯视刻度线，读数偏大，实际液面低于刻度线，V 偏小→c 偏高。C 对：未洗涤，溶质残留于烧杯和玻璃棒上，n 偏小→c 偏低。D 对：摇匀后液面下降是正常现象（溶液附着于容量瓶壁），若再加水至刻度线会使 V 偏大→c 偏低。
13.
下列说法正确的有（　）（已知 O 的摩尔质量为 16 g·mol⁻¹）
答案：B, C — A 错：O₂ 的摩尔质量为 32 g·mol⁻¹，n(O₂) = 16 g / 32 g·mol⁻¹ = 0.5 mol。B 对：每个 O₂ 分子含 2 个 O 原子，n(O) = 0.5 mol × 2 = 1 mol，故 O 原子数为 N_A。C 对：CO₂ 的摩尔质量为 44 g·mol⁻¹，n(CO₂) = 44 g / 44 g·mol⁻¹ = 1 mol，标况下体积 = 22.4 L。D 错：1 mol NaCl 溶于 1 L 水后溶液体积大于 1 L，浓度小于 1 mol·L⁻¹。

三、填空题（共6题，每题3分，共18分）

14. \(0.5\ \text{mol}\ \text{CO}_2\) 中含有
个 CO₂ 分子， 含有 个原子（含 C 和 O 原子总数）。
答案：3.01×10²³；9.03×10²³ — N(CO₂) = n × N_A = 0.5 × 6.02×10²³ = 3.01×10²³（分子数）；每个 CO₂ 分子含 3 个原子（1C + 2O），故原子总数 = 3 × 3.01×10²³ = 9.03×10²³。
15. \(1.5\ \text{mol}\ \text{H}_2\text{O}\) 的质量为
g， 含有 mol H 原子。
答案：27；3 — m(H₂O) = n × M = 1.5 mol × 18 g·mol⁻¹ = 27 g；每个 H₂O 分子含 2 个 H 原子，故 n(H) = 1.5 × 2 = 3 mol。
16. 标准状况下，\(6.72\ \text{L}\ \text{N}_2\) 的物质的量为
mol， 所含 N₂ 分子的数目为 个。
答案：0.3；1.806×10²³ — n(N₂) = V / V_m = 6.72 L / 22.4 L·mol⁻¹ = 0.3 mol；N(N₂) = n × N_A = 0.3 × 6.02×10²³ = 1.806×10²³。
17. 将 0.4 mol NaOH 溶于水配成 500 mL 溶液，所得溶液浓度为
mol·L⁻¹； 从中取出 50 mL，其物质的量浓度为 mol·L⁻¹。
答案：0.8；0.8 — c(NaOH) = n / V = 0.4 mol / 0.5 L = 0.8 mol·L⁻¹。溶液具有均一性，取出任意体积的溶液，其浓度与剩余部分相同，仍为 0.8 mol·L⁻¹，但所含溶质的物质的量会减少。
18. 0.2 mol CH₄ 中含有
个 CH₄ 分子， 含有 mol H 原子。
答案：1.204×10²³；0.8 — N(CH₄) = 0.2 × 6.02×10²³ = 1.204×10²³；每个 CH₄ 分子含 4 个 H 原子，故 n(H) = 0.2 × 4 = 0.8 mol。
19. 配制 250 mL 0.2 mol·L⁻¹ NaCl 溶液，需要量取 2.0 mol·L⁻¹ NaCl 溶液
mL。 （可选项：25 mL / 50 mL / 100 mL 量筒，应选择 mL 量筒。）
答案：25；25 — 稀释公式 c₁V₁ = c₂V₂，2.0 × V₁ = 0.2 × 250，解得 V₁ = 25.0 mL。量筒选择原则"一次量取，选用略大于所需体积的规格"，故选用 25 mL 量筒（若用 50 mL 量筒量取 25 mL 误差较大）。

四、解答题（共4题，共40分）

20. （10分）物质的量与质量、粒子数的换算
(1)（3分）计算 11 g CO₂ 的物质的量。（M(CO₂) = 44 g·mol⁻¹）
(2)（3分）计算 11 g CO₂ 中含有的 CO₂ 分子数目。
(3)（4分）计算 11 g CO₂ 在标准状况下的体积；若将该 CO₂ 全部溶于水配成 500 mL 溶液，所得溶液中 CO₂（视为溶质）的物质的量浓度是多少？
参考答案：
(1)（3分）n(CO₂) = m / M = 11 g / 44 g·mol⁻¹ = 0.25 mol
(2)（3分）N(CO₂) = n × N_A = 0.25 × 6.02×10²³ = 1.505×10²³（个）
(3)（4分）V(CO₂) = n × V_m = 0.25 × 22.4 = 5.6 L（标况）（2分）
c(CO₂) = n / V = 0.25 mol / 0.5 L = 0.5 mol·L⁻¹（2分）
21. （10分）气体摩尔体积综合计算
(1)（3分）标准状况下，6.72 L N₂ 和 6.72 L O₂ 的混合气体中共含多少摩尔分子？
(2)（3分）标准状况下，4.48 L H₂ 的质量为多少克？（M(H₂) = 2 g·mol⁻¹）
(3)（4分）同温同压下，体积相同的 H₂ 和 O₂，其物质的量之比为 ； 分子数之比为 ； 质量之比为 。
参考答案：
(1)（3分）混合气体总物质的量：n(总) = V₁/V_m + V₂/V_m = 6.72/22.4 + 6.72/22.4 = 0.3 + 0.3 = 0.6 mol
(2)（3分）n(H₂) = 4.48 / 22.4 = 0.2 mol；m(H₂) = n × M = 0.2 × 2 = 0.4 g
(3)（4分）同温同压下，体积比 = 物质的量比 = 分子数比，故 H₂ : O₂ 物质的量之比 = 1:1，分子数之比 = 1:1（各2分）
质量比 = (n×M₁) : (n×M₂) = M(H₂) : M(O₂) = 2 : 32 = 1:16（2分）
22. （10分）配制一定物质的量浓度溶液
(1)（2分）实验室欲配制 100 mL 0.5 mol·L⁻¹ CuSO₄ 溶液，需要 CuSO₄·5H₂O（胆矾，M=250 g·mol⁻¹）的质量为 g。
(2)（4分）请写出完整的配制步骤（简要操作过程，包括所需仪器）。
(3)（4分）若在配制过程中，定容时仰视刻度线，对所配溶液浓度将有何影响？请说明原因。另举一个可能导致浓度偏低的操作。
参考答案：
(1)（2分）n(CuSO₄) = 0.5 × 0.1 = 0.05 mol → n(CuSO₄·5H₂O) = 0.05 mol → m = 0.05 × 250 = 12.5 g
(2)（4分）步骤：① 计算（求所需胆矾质量）→ ② 称量（用托盘天平称取 12.5 g 胆矾）→ ③ 溶解（在烧杯中用适量蒸馏水溶解，玻璃棒搅拌）→ ④ 转移（冷却后转移至 100 mL 容量瓶）→ ⑤ 洗涤（用蒸馏水洗涤烧杯和玻璃棒 2~3 次，洗涤液一并转入容量瓶）→ ⑥ 定容（加蒸馏水至液面离刻度线 1~2 cm，改用胶头滴管滴加至凹液面最低处与刻度线相切）→ ⑦ 摇匀（盖好瓶塞，上下颠倒摇匀）。
所需仪器：托盘天平（含砝码）、药匙、烧杯、玻璃棒、100 mL 容量瓶、胶头滴管、量筒。
(3)（4分）仰视定容：导致实际液面高于刻度线，溶液体积 V 偏大 → 浓度偏低（2分）。
其他导致浓度偏低的操作示例：① 未洗涤烧杯和玻璃棒（溶质残留）；② 称量时砝码生锈（实际称取质量偏小——修正：砝码生锈实际质量偏大会导致称取溶质偏多，应改为"砝码有缺损"或"称量时左码右物"）；③ 溶解后未冷却至室温即转移（热溶液体积膨胀，冷却后 V 偏小，浓度偏高——故此条不对）。正确示例：称量前天平未调零（偏左），导致称取溶质偏少 → 浓度偏低。（2分，合理即可）
23. （10分）综合计算
(1)（3分）计算 0.5 mol Na₂CO₃·10H₂O 的质量。（M = 286 g·mol⁻¹）
(2)（3分）0.5 mol Na₂CO₃·10H₂O 中含 Na⁺ 的物质的量是多少？含结晶水 H₂O 的分子数是多少？
(3)（4分）将该 0.5 mol Na₂CO₃·10H₂O 全部溶于水配成 500 mL 溶液，求 Na⁺ 的物质的量浓度；若将该溶液稀释 5 倍，稀释后 Na₂CO₃ 的物质的量浓度是多少？
参考答案：
(1)（3分）m = n × M = 0.5 × 286 = 143 g
(2)（3分）每个 Na₂CO₃·10H₂O 中含 2 个 Na⁺，n(Na⁺) = 0.5 × 2 = 1.0 mol（1.5分）
每个 Na₂CO₃·10H₂O 中含 10 个结晶水分子，n(H₂O) = 0.5 × 10 = 5 mol，N(H₂O) = 5 × 6.02×10²³ = 3.01×10²⁴（1.5分）
(3)（4分）c(Na⁺) = n(Na⁺) / V = 1.0 mol / 0.5 L = 2.0 mol·L⁻¹（2分）
稀释 5 倍，即稀释后体积为原体积的 5 倍，c(Na₂CO₃) 稀释后 = c(原) / 5 = (0.5/0.5) / 5 = 1.0 / 5 = 0.2 mol·L⁻¹（2分）
（也可用稀释公式 c₁V₁ = c₂V₂：设稀释后体积为 V₂ = 5V₁，则 c₂ = c₁V₁ / V₂ = 1.0 × 1 / 5 = 0.2 mol·L⁻¹）
